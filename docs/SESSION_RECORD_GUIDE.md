# 采集会话录制与回放

把一段采集完整录下来存成文件，之后重新载入解析。串口、RTT 和蓝牙三个工作台都支持。

## 解决什么问题

导出 TXT / CSV / PNG 都是单向的，导出后无法再走一遍解析和绘图。于是：

- 想对比两组滤波参数，只能把现象**重新复现一遍**
- 现场抓到的异常，没法原样交给别人分析
- 设备不在手边时，没法重新查看当时的波形

录制保存的是**原始字节流**而不是解析后的数值，回放时会重新走完整的分帧、解析、滤波链路，就像设备又发了一遍。

## 怎么用

**录制**：工具栏 → 更多 → 工作流 → **录制会话**。按钮左侧的圆点变红、文字变为 **停止并保存**，表示正在录制，此时收到的原始字节都会被留存。

**保存**：点击 **停止并保存** → 选择保存位置。文件扩展名是 `.ekrec`。保存成功后日志会显示文件路径、数据块数和字节数；本次录制没有收到任何数据时不会弹出保存框，日志提示 "本次录制没有收到任何数据，未保存"。

**回放**：更多 → 工作流 → **回放会话** → 选择 `.ekrec` 文件。图表会先清空，然后填入回放解析出的数据。日志会显示回放的数据块数、解析出的数据点数、RTT 通道号和录制时间；有解析失败的帧时另行提示。

> 回放只填充图表，不会把内容写回文本区，文本区的历史内容不受影响。

## 文件里存了什么

| 内容 | 用途 |
| --- | --- |
| 原始字节流 | 回放时重新走完整的分帧、解析、滤波链路 |
| 每块的相对时间 | 还原数据到达的时序 |
| RTT 通道号 | 回放时按通道分别拼帧，避免跨通道串数据 |
| 录制时的图表配置 | 回放时使用，含解析模式、通道、滤波参数 |
| 接收分帧设置 | 串口和 RTT，回放时按录制时的断行方式拼帧；蓝牙按默认的换行方式分帧 |

文件是 NDJSON 文本格式（每行一条 JSON），可以用文本编辑器打开查看，首行即为上述配置信息。

## 回放时的配置

回放使用的是**文件里保存的图表配置**：回放会把当前工作台的图表配置替换为录制时的配置，再用它解析数据。因此：

- **录制前先配好并启用图表解析。** 录制时图表解析未启用，回放不会产生数据点
- **调滤波参数**：回放后直接修改滤波参数，图表会对已回放的数据立即重新计算，适合录一段带噪声的真实信号反复试不同截止频率。滤波设置见 [数据滤波与 MATLAB 参数](MATLAB_FILTER_GUIDE.md)
- **修改解析模式或通道**不会重新解析已回放的数据；再次回放时仍会恢复为文件里的配置

典型场景：

- **调滤波参数**：录一段真实信号，回放后反复调整滤波，每次都作用在完全相同的数据上
- **复现现场问题**：把现场录的 `.ekrec` 交给同事，对方回放即可看到同样的波形
- **回归对照**：升级固件后录一段新数据，与旧版本的录制文件分别回放对比

## 注意事项

**只录接收方向。** 发出去的内容不是设备上报的数据，不参与录制。

**容量上限 32 MB。** 超出后停止追加，已录部分仍可正常保存和回放；保存时日志会提示「录制超出容量上限，文件只包含前一部分数据」。高速数据下这个上限很快会到，建议只录关注的那一段。

**录制不影响实时显示。** 录制期间图表、日志、终端照常工作。

**回放前会清空当前图表。** 避免回放数据与实时数据混在一起；如果设备仍在发送，新数据会接着回放数据继续绘制，建议回放前先停止接收。

**跨工作台回放会提示。** 例如把 RTT 录的文件在串口工作台回放，日志会提示 "该文件录制自「rtt」，正在当前工作台回放，解析配置可能不适用"——文件仍会回放，但需自行确认配置是否合适。
