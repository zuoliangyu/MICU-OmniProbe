# 日志分析使用指南

日志分析工作台用于离线查看和分析已经保存的日志文件，不需要连接探针或串口设备。

## 导入日志

1. 从左侧选择 `日志` 工作台。
2. 点击 `导入日志`，选择 UTF-8 编码的 `.log` 或 `.txt` 文件。
3. 等待界面显示文件名、大小和已导入行数。
4. 使用搜索框筛选正文，或在 `文本`、`分屏`、`图表`之间切换。

大文件会分批读取。导入期间可以看到当前行数，点击 `清空` 或重新选择文件即可停止使用当前内容。

也可以点击 `模拟数据`，直接载入 1000 条由串口工作台当前模拟配置生成的数据。工作台会自动选择 `SIM:` 前缀、识别 JSON 通道并切换到分屏视图，适合在没有设备和日志文件时验证解析与图表配置。

## 时间戳格式

日志分析会识别下面的行首时间戳：

```text
[20260724_13:18:19:567]temperature:25.3,voltage:3.30
```

格式为 `[yyyyMMdd_HH:mm:ss:fff]正文`。时间戳会显示在文本视图中，但不会作为正文参与搜索和数值解析。

没有有效时间戳的行仍会保留：它会继承上一行的时间；如果首行也没有时间戳，则使用本次导入开始时的时间。界面会提示有多少行使用了推断时间。

## 搜索与图表

- `文本`：查看和搜索全部日志正文。
- `分屏`：同时查看日志正文和解析后的图表。
- `图表`：集中查看数值曲线。
- `通道`：快速勾选需要显示的曲线。
- `高级设置`：选择自动、JSON、KV、分隔符或正则等解析方式，并配置名称、单位、颜色和最大数据点数。

### 定位栏（时间跳转与查找）

文本区底部的定位栏在串口、RTT、蓝牙和日志分析中通用，只跳转、不过滤，前后文保持可见：

- **时间跳转**：点击时间框会预填当前位置的时间并全选，可直接输入 `HH:mm:ss.SSS`（日期取当前位置所在日期）或 `YYYY-MM-DD HH:mm:ss.SSS`，回车跳到时间最接近的一行，并提示偏差毫秒数。
- **查找**：`文本` 模式按关键词（不区分大小写）查找；`HEX` 模式按原始字节序列查找，如 `AA 55 01`。Enter 下一个、Shift+Enter 上一个，到头后自动绕回，并显示"第几个 / 共几个"。未定位时从可视区第一行开始向后找。
- 定位后该行高亮，自动滚动暂停，新数据不会把视图拉回底部；点击 `取消定位` 恢复跟随。
- 顶部搜索框仍用于过滤，定位栏在过滤后的结果中查找。

数值格式与实时数据工作台一致，详见 [输入数据解析格式](DATA_FORMAT_GUIDE.md)。日志很大时，图表会分批解析并显示进度；最终保留的数据量受“最大数据点数”限制。

### 按前缀选择分析内容

导入完成后，“分析前缀”会列出日志中检测到的行首前缀和对应行数，例如 `P:`、`D:` 或 `@PLOT:`。选择一个前缀后，图表只处理此前缀的数据，其他日志仍保留在文本视图中。

- 纯数字分隔数据会自动识别分隔符并建立通道，例如 `P:1,2,3`。
- `key=value` 和 `key:value` 数据会按字段名自动建立通道，例如 `D:water:1,power:86`。
- 不能自动识别的内容会提示“待配置解析规则”，可继续打开“高级设置”选择正则表达式或已安装的解析插件。
- 当前一次分析一个前缀；切换前缀会重新生成相应的图表数据。

### 预览正则提取结果

选择“正则表达式”后，可以同时填写表达式和一条数据样本。界面会立即显示是否匹配，以及每个命名捕获组提取到的数值。

例如数据样本：

```text
D:mid:0,water:1,power:86,dtgt:2,soft:3
```

数据帧前缀填写 `D:`，正则表达式填写：

```regex
mid:(?<mid>-?\d+),water:(?<water>-?\d+),power:(?<power>-?\d+),dtgt:(?<dtgt>-?\d+),soft:(?<soft>-?\d+)
```

预览成功后会得到 `mid`、`water`、`power`、`dtgt` 和 `soft` 五个数值通道，再保存配置即可解析整份日志。

## 当前限制

- 仅支持 UTF-8 文本文件。
- 默认只识别 `[yyyyMMdd_HH:mm:ss:fff]` 时间戳格式。
- 日志分析是只读工作台，不会修改原文件。
