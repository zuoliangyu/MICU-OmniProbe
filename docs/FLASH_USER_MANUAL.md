# 烧录工作台用户手册

烧录工作台用于把编译好的固件写入目标芯片的 Flash，并提供擦除、校验和读取 Flash 等操作。探针、芯片和连接参数都在右侧 **配置检查器** 中设置，RTT 工作台也会复用这里建立的连接。

## 快速开始

1. 点击左侧模式轨道的 **烧录**，或按 `Ctrl+1`，进入烧录工作台
2. 把探针插到电脑 USB 口，并用 SWD / JTAG 线连接目标板，目标板正常供电
3. 在右侧 **调试探针** 卡片中选择探针（插入后会自动出现在列表里）
4. 在 **目标芯片** 卡片的搜索框输入型号（如 `STM32F103C8`），从结果中点击选择
5. 点击右侧底部的 **连接设备**
6. 点击主区域的 **选择固件文件**，或把固件文件直接拖到窗口中
7. 点击工具栏的 **烧录**，在固件卡片和底部日志中查看进度

烧录完成后，如果勾选了 **烧录后复位**（默认勾选），芯片会自动复位运行新固件。

## 配置检查器

右侧配置检查器可以通过顶栏按钮收起或展开。连接成功后，探针、芯片和接口设置（复位方式除外）会被锁定，需要修改时先 **断开连接**。

### 调试探针

- 插入或拔出探针后列表自动更新；也可以点击卡片右上角的刷新按钮（"刷新探针列表"）重新检测
- 未选择时卡片下方显示 "已检测 N 个探针"，选择后显示探针名称
- CMSIS-DAP / DAPLink 探针会附带版本标签：`DAPv1 (HID)`、`DAPv2 (WinUSB)` 或 `DAPv1+v2 (HID/WinUSB)`
- 探针有需要注意的情况时（例如 J-Link 缺少官方运行库），卡片下方会用黄色文字提示；连接失败的原因用红色文字显示

支持的探针：

| 探针                | 说明                                                                                              |
| ------------------- | ------------------------------------------------------------------------------------------------- |
| CMSIS-DAP / DAPLink | 主要验证的探针，支持 DAPv1 HID 与 DAPv2 WinUSB                                                    |
| J-Link（Windows）   | 安装 SEGGER 官方软件后自动识别，安装要求和限制见 [快速入门](QUICK_START.md#windows-上使用-j-link) |
| ST-Link 等          | 底层 probe-rs 支持的其他探针理论上可用，但并非所有型号都经过验证                                  |

### 目标芯片

- 在 **搜索芯片型号...** 输入框中至少输入 2 个字符开始搜索，不区分大小写，按型号中包含的文字匹配，最多显示 50 条结果
- 点击结果即可选中，主区域随即显示该芯片的信息
- **最近连接**：连接成功过的芯片会被记住（最多 8 个，最新的在前，重启软件后仍在）。未连接时点击空白的搜索框，即可从 "最近连接" 列表中直接选择
- 搜索不到芯片时，可在 [Pack 管理](#pack-管理) 中导入该芯片厂商的 CMSIS-Pack

### 接口设置

点击 **接口设置** 卡片标题展开，标题下方会显示当前设置摘要（如 `SWD · 1 MHz · Normal`）。

| 选项     | 可选值                                             | 默认值   | 说明                                                                                          |
| -------- | -------------------------------------------------- | -------- | --------------------------------------------------------------------------------------------- |
| 接口类型 | SWD / JTAG                                         | SWD      | 与目标板的调试接口一致                                                                        |
| 时钟速度 | 100 kHz / 500 kHz / 1 MHz / 2 MHz / 4 MHz / 10 MHz | 1 MHz    | 线较长或连接不稳定时调低，连接稳定时可调高以加快烧录                                          |
| 连接模式 | 正常 / 复位下连接                                  | 正常     | 固件关闭了调试引脚、进入低功耗或连接不上时，改用 "复位下连接"（需要探针的复位线已接到目标板） |
| 复位方式 | 软件复位 / 硬件复位                                | 软件复位 | 烧录与调试工具栏的 **复位**、以及 **烧录后复位** 使用的复位方式，连接期间也可以切换，见下方说明 |

复位方式：

- **软件复位**：通过调试接口让芯片内核发起系统复位，不需要额外接线，适用于大多数情况
- **硬件复位**：由探针拉低芯片的复位引脚（nRST），需要探针的复位线已接到目标板。固件把系统复位屏蔽或改写了复位行为时使用。目前仅支持 ARM 内核芯片；复位线未接或探针不支持时，日志会提示失败原因，请改回软件复位
- 复位方式只影响复位操作本身；"复位下连接" 由 **连接模式** 决定，与这里的选择无关

接口设置在重启软件后恢复为默认值，可以通过 [烧录项目](#烧录项目) 保存和恢复。

### 自动断开

点击 **自动断开** 卡片标题展开。开启后，窗口内一段时间没有鼠标、键盘或滚动操作时，软件会自动断开烧录连接，释放探针给其他软件使用。

| 选项           | 说明                                                  |
| -------------- | ----------------------------------------------------- |
| 启用自动断开   | 点击按钮在 "已启用" / "已禁用" 之间切换，**默认启用** |
| 超时时间（秒） | 5 / 10 / 30 / 60 / 120 / 300 秒，**默认 10 秒**       |

- RTT 运行时不会自动断开
- 烧录、擦除、校验、读取 Flash 和解锁芯片进行中不会自动断开；操作结束后重新开始计时
- 卡片标题下方显示当前状态，例如 "10 秒无操作自动断开" 或 "当前关闭"
- 设置在重启软件后恢复为默认值

### 连接信息

连接成功后出现 **连接信息** 卡片，显示：

| 字段      | 说明                                       |
| --------- | ------------------------------------------ |
| DAP版本   | CMSIS-DAP 探针的协议版本                   |
| DAP序列号 | 探针序列号                                 |
| 目标      | 当前连接的芯片型号                         |
| 内核      | 芯片内核类型                               |
| 芯片ID    | 从芯片读取到的器件 ID（能读到时才显示）    |
| DP IDCODE | 调试端口标识码，可用于确认调试接口通信正常 |

### 连接与断开

- 右侧底部的 **连接设备** 按钮在选好探针和芯片后可用；缺少某一步时，按钮上方会提示 "未检测到探针，插入后将自动识别"、"请先选择调试探针" 或 "请先搜索并选择目标芯片"
- 连接中按钮显示 "连接中..."，成功后变为红色的 **断开连接**
- 断开连接时不会复位芯片，芯片保持继续运行
- 已在烧录工作台连接时，RTT 工作台可以直接使用这个连接启动，详见 [RTT 用户手册](RTT_USER_MANUAL.md)

## 选择固件

有三种方式选择固件：

1. 点击固件卡片中的 **选择固件文件**（已选择时为 **更换固件**）
2. 点击工具栏最左侧的 **打开固件文件** 图标
3. 把固件文件直接拖到窗口中，出现 "释放以选择固件文件" 提示后松开。同时拖入多个文件时只使用第一个

支持的固件格式：

| 格式      | 扩展名                 | 烧录地址                                                                                 |
| --------- | ---------------------- | ---------------------------------------------------------------------------------------- |
| Intel HEX | `.hex`、`.ihex`        | 文件自带地址                                                                             |
| ELF       | `.elf`、`.axf`、`.out` | 文件自带地址（Keil 生成的 `.axf` 属于此类）                                              |
| 二进制    | `.bin`                 | 文件不含地址，默认写到芯片主 Flash 的起始地址，可用 [自定义ROM地址](#自定义rom地址) 修改 |

通过 "所有文件" 选择其他扩展名的文件时，会按 ELF 格式解析。

每次点击 **烧录** 时都会重新读取固件文件，重新编译后无需再次选择，直接烧录即可得到最新的结果。

| 按钮 / 选项  | 说明                                                                          | 可用条件                         |
| ------------ | ----------------------------------------------------------------------------- | -------------------------------- |
| 打开固件文件 | 选择要烧录的固件                                                              | 随时                             |
| 打开项目     | 打开 `.omniproj` 项目文件，恢复固件、芯片和各项设置，见 [烧录项目](#烧录项目) | 非烧录中                         |
| 保存项目     | 把当前固件、芯片和各项设置保存为 `.omniproj` 项目文件                         | 随时                             |
| 解锁芯片     | 整片擦除芯片以解除读保护，见 [解锁芯片](#解锁芯片)                            | 已选择探针和芯片，未连接也可使用 |
| 擦除         | 打开 "擦除 Flash" 对话框，见 [擦除 Flash](#擦除-flash)                        | 已连接                           |
| 烧录模式     | 烧录时的擦除方式：**扇区擦除**（默认）或 **整片擦除**，见下表                 | 非烧录中                         |
| 校验         | 比对 Flash 内容与固件文件，见 [校验与读取](#校验与读取)                       | 已连接且已选择固件               |
| 读取         | 读取指定范围的 Flash 内容并保存为 `.bin` 文件                                 | 已连接                           |
| 烧录         | 一键烧录当前固件                                                              | 已连接且已选择固件               |
| 复位         | 按配置检查器中的复位方式复位芯片，见 [复位、停止与运行](#复位停止与运行)      | 已连接                           |
| 停止         | 暂停芯片内核                                                                  | 已连接                           |
| 运行         | 让暂停的内核继续运行                                                          | 已连接                           |

烧录、擦除、校验、读取或解锁进行中，其他会访问芯片的按钮暂时不可用。

烧录模式：

| 模式     | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| 扇区擦除 | 只擦除固件要写入的扇区，速度快；固件未覆盖的其他扇区保持不变 |
| 整片擦除 | 烧录前清空整个 Flash，速度较慢但彻底                         |

烧录模式、烧录后校验和烧录后复位的选择会自动保存，下次启动沿用。

### 烧录过程

点击 **烧录** 后，固件卡片中显示进度条、当前步骤和百分比，大致分为以下阶段：

1. 重新读取固件文件
2. 擦除需要写入的区域（选择整片擦除时擦除整片）
3. 编程写入数据
4. 勾选了烧录后校验时进行校验
5. 勾选了烧录后复位时复位芯片

结束后日志显示 "烧录成功" 或 "烧录失败" 及原因。

RTT 正在运行时也可以直接烧录：烧录期间 RTT 暂停读取，完成后自动重新查找控制块并继续接收。

## 烧录项目

项目文件（扩展名 `.omniproj`）把一次烧录需要的设置存在一起，换电脑、换板子或在多个工程之间切换时，打开项目即可一次恢复。

**保存项目**：点击工具栏的 **保存项目**，选择保存位置。默认文件名取自当前固件文件名。项目中保存：

| 内容     | 包括                                                          |
| -------- | ------------------------------------------------------------- |
| 固件     | 固件文件的完整路径（保存的是路径，不包含固件内容）            |
| 目标芯片 | 当前选择的芯片型号                                            |
| 接口设置 | 接口类型、时钟速度、连接模式、复位方式                        |
| 烧录设置 | 烧录模式、烧录后校验、烧录后复位、自定义 ROM 地址及其起始地址 |

**打开项目**：点击工具栏的 **打开项目**，选择 `.omniproj` 文件：

- 未连接时恢复全部内容：选中项目中的芯片、套用接口设置和烧录设置、选中固件
- 已连接时，芯片与接口设置不能修改，只恢复复位方式、烧录设置和固件；日志会提示断开连接后重新打开项目即可全部恢复
- 固件文件已被移动或删除时，日志提示 "文件不存在"，其他设置照常恢复
- 项目中的芯片需要导入 Pack 才能识别时，先在 [Pack 管理](#pack-管理) 中导入，否则日志会提示芯片加载失败
- 项目文件是 JSON 文本，可以用文本编辑器查看；手动修改出错的项会被忽略，保持当前设置

## 烧录设置

主区域右下角的 **烧录设置** 卡片：

| 选项          | 默认   | 说明                                                               |
| ------------- | ------ | ------------------------------------------------------------------ |
| 烧录后校验    | 不勾选 | 写入后回读比对，确认烧录正确，适用于所有固件格式；会增加烧录时间   |
| 烧录后复位    | 勾选   | 烧录完成后按配置检查器中的 **复位方式** 复位芯片，让新固件立即运行 |
| 自定义ROM地址 | 不勾选 | 为 BIN 固件指定烧录起始地址                                        |

### 自定义ROM地址

勾选 **自定义ROM地址** 后出现 **IROM1 起始地址** 输入框（十六进制，默认 `0x08000000`）：

- 仅对 BIN 固件生效，HEX / ELF 自带地址，不受影响
- 烧录和工具栏 **校验** 都使用这个地址
- 点击 **使用芯片默认值** 可填入当前芯片第一个 Flash 区域的起始地址
- 典型用途：Bootloader + App 分区时，把 App 的 BIN 烧到 App 分区起始地址

该选项在重启软件后恢复为不勾选，可以通过 [烧录项目](#烧录项目) 保存。

## 擦除 Flash

点击工具栏 **擦除**，在 "擦除 Flash" 对话框中选择擦除方式。擦除后数据无法恢复，请谨慎操作。

| 方式             | 说明                                                                          |
| ---------------- | ----------------------------------------------------------------------------- |
| 全片擦除（推荐） | 擦除整个 Flash 存储器                                                         |
| 自定义范围擦除   | 擦除指定地址范围，需填写 **起始地址（十六进制）** 和 **擦除大小（十六进制）** |

自定义范围擦除：

- 默认值为起始 `0x08000000`、大小 `0x10000`（64 KB）
- 地址和大小不要求与扇区对齐，范围覆盖到的扇区会被整个擦除，因此实际擦除的范围可能比填写的略大
- 单次擦除大小上限 64 MB

点击 **确认擦除** 开始，日志中显示 "全片擦除完成" 或 "自定义范围擦除完成"。

## 校验与读取

### 校验

工具栏的 **校验** 按钮把 Flash 中的内容与固件文件逐字节比对，不会改写芯片，芯片可以保持运行：

- 支持所有固件格式：HEX、BIN、ELF（含 `.axf`、`.out`）
- HEX / ELF 按文件中记录的地址逐段比对；固件中加载到 RAM 的段不参与比对（程序运行后 RAM 内容本来就会变化）
- BIN 的起始地址与烧录时一致：勾选了自定义 ROM 地址时使用该地址，否则使用芯片主 Flash 起始地址
- 结果显示为 "校验通过" 或 "校验失败"；不一致时日志会给出第一个不匹配的地址，以及芯片和固件在该处的字节值

### 读取

工具栏的 **读取** 按钮打开 "读取 Flash" 对话框：

| 项目         | 说明                                                                         |
| ------------ | ---------------------------------------------------------------------------- |
| 快速选择区域 | 列出芯片的各个 Flash 区域，点击即可把该区域的起始地址和大小填入下方          |
| 起始地址     | 十六进制，可带或不带 `0x`；默认是芯片主 Flash（第一个 Flash 区域）的起始地址 |
| 读取长度     | 十六进制；默认是主 Flash 的完整大小，输入框下方显示换算后的大小              |

- 点击 **选择保存位置并读取**，选择保存位置后开始读取，结果保存为 `.bin` 文件；默认文件名包含芯片型号、起始地址和长度
- 单次最多读取 64 MB；读取较大的 Flash 需要一些时间，完成后日志显示读取的字节数和保存路径
- 同一芯片下对话框会保留上次填写的范围；换芯片后恢复为新芯片的默认值
- 芯片处于读保护状态时读出的内容可能全为 0 或读取失败

## 复位、停止与运行

工具栏最右侧的三个按钮用于在烧录连接下直接控制芯片，结果写入日志：

| 按钮 | 作用                                                                                           |
| ---- | ---------------------------------------------------------------------------------------------- |
| 复位 | 按配置检查器 **接口设置** 中的 **复位方式**（软件复位 / 硬件复位）复位芯片，复位后芯片继续运行 |
| 停止 | 暂停芯片内核，日志显示停下时的程序计数器（PC）地址                                             |
| 运行 | 让暂停的内核继续运行                                                                           |

- 鼠标悬停在 **复位** 按钮上可以看到当前使用的复位方式
- RTT 正在使用烧录连接时，复位后 RTT 会自动重新查找控制块
- 需要断点、单步、查看寄存器和变量时，请使用 [调试工作台](DEBUG_USER_MANUAL.md)

## 解锁芯片

芯片开启了读保护或被锁定、无法正常烧录时，可以用工具栏的 **解锁芯片** 整片擦除芯片来解除保护。

1. 在配置检查器中选好探针和芯片（不需要先连接；已连接时会断开原连接重新建立）
2. 点击工具栏的 **解锁芯片**（锁形图标）
3. 阅读确认对话框中的提示，点击 **擦除并解锁**
4. 完成后日志显示 "已解锁并完成全片擦除"，并自动保持连接，可以直接烧录新固件

注意事项：

- **解锁会清除芯片中的全部程序和数据**，包括读保护下无法读出的内容，且不可恢复
- 芯片定义中带有解锁流程的芯片（如 nRF 系列的 APPROTECT、部分 Microchip ATSAM、Silicon Labs、Infineon、NXP 芯片）会在解锁时解除保护，芯片被锁、普通连接失败时也可以使用
- 其他芯片只执行一次整片擦除。需要修改选项字节才能解除的保护（如 STM32 的 RDP 读保护）无法在这里解除，请使用芯片厂商工具（如 STM32CubeProgrammer）
- 解锁使用配置检查器中的接口设置；连接不上时可尝试把连接模式改为 **复位下连接**
- 解锁失败时原有的烧录连接已经断开，需要重新连接

## Pack 管理

芯片列表来自内置的芯片定义。内置定义里没有的芯片，可以导入厂商提供的 Keil CMSIS-Pack（`.pack` 文件）来扩展芯片和 Flash 算法。

### 导入 Pack

- 点击 **Pack 管理** 卡片标题右侧的 **导入**，可一次选择多个 `.pack` 文件
- 也可以把 `.pack` 文件拖到窗口中，Pack 管理卡片会自动展开并提示 "释放以导入 Pack 文件"，支持同时拖入多个

导入时卡片中显示扫描进度，依次经过 "解析PDSC"、"提取设备"、"查找算法"、"匹配算法"、"生成配置"、"注册设备" 等阶段。导入成功后，Pack 中的芯片即可在目标芯片中搜索到。

### 已导入的 Pack

展开卡片可以看到已导入的 Pack 列表，每项显示名称、厂商、版本、描述和包含的设备数量：

| 按钮         | 说明                                                                                    |
| ------------ | --------------------------------------------------------------------------------------- |
| 查看扫描报告 | 打开 "Pack 扫描报告"：总设备数、有算法 / 无算法的设备数、算法使用统计、无算法的设备列表 |
| 删除Pack     | 确认后删除该 Pack，删除后需要重新导入才能使用                                           |

扫描报告中 "无算法" 的设备没有匹配到 Flash 算法，通常无法烧录。

### Pack 存储目录

点击卡片标题上的齿轮按钮（"Pack 目录设置"）显示当前 Pack 存储目录：

- **更改目录**：选择新的存储目录
- **重置**：恢复默认目录

更改或重置目录后需要重启软件才能生效。

## Linux USB 权限配置

在 Linux 上，普通用户访问 USB 探针需要安装 udev 规则。软件启动时检测到规则未安装，会弹出 "USB 调试器权限配置" 对话框：

- 显示 **USB 权限** 和 **udev 规则** 的状态，以及检测到的调试器列表
- 点击 **自动安装 udev 规则**，按系统提示输入密码即可安装；安装成功后重新插拔调试器
- 不方便自动安装时，按对话框中的 "手动安装方法" 操作：

  ```bash
  sudo cp 99-zuolan-daplink.rules /etc/udev/rules.d/
  sudo udevadm control --reload-rules
  sudo udevadm trigger
  ```

  然后重新插拔调试器

- 点击 **稍后配置** 关闭对话框

## 常见问题

### 1. 探针列表为空

**解决方法：**

1. 确认 USB 线连接正常，尝试重新插拔探针或更换 USB 口
2. 点击 **调试探针** 卡片右上角的刷新按钮
3. Windows 下确认探针驱动正常；J-Link 需要安装 SEGGER 官方软件，见 [快速入门](QUICK_START.md#windows-上使用-j-link)
4. Linux 下确认已安装 udev 规则，见 [Linux USB 权限配置](#linux-usb-权限配置)
5. 探针正被 Keil、IAR 等其他软件占用时，先在那边结束调试会话

### 2. 连接失败

连接失败时日志会提示：芯片型号是否正确、是否已导入对应的 Pack 文件、硬件连接是否正常。

**解决方法：**

1. 确认目标板已供电，SWD 的 SWDIO、SWCLK、GND 接线正确
2. 确认选择的芯片型号与实物一致
3. 在 **接口设置** 中把时钟速度降到 500 kHz 或 100 kHz 再试
4. 固件关闭了 SWD 引脚或芯片进入低功耗时，把连接模式改为 **复位下连接**（需要接复位线）
5. 探针正被 RTT 工作台的独立连接或调试工作台的调试会话使用时，先在对应工作台断开

### 3. 搜索不到芯片

1. 至少输入 2 个字符，尝试只输入型号的一部分（如 `F103`）
2. 搜索结果最多显示 50 条，请输入更完整的型号缩小范围
3. 仍然找不到时，在 [Pack 管理](#pack-管理) 中导入该芯片的 CMSIS-Pack

### 4. 烧录失败或进度卡住

1. 在 **烧录算法** 卡片确认该芯片有可用算法；Pack 导入的芯片可在扫描报告中查看是否 "无算法"
2. 把烧录模式改为 **整片擦除**，或先用 **擦除** 做一次全片擦除后再烧录
3. 降低时钟速度后重新连接
4. BIN 固件确认起始地址正确，见 [自定义ROM地址](#自定义rom地址)
5. 芯片开启了读保护或被锁定时，先用 [解锁芯片](#解锁芯片) 整片擦除

### 5. 工具栏校验提示 "固件中没有位于 Flash 地址范围内的数据"

固件中的地址不在当前芯片的 Flash 范围内：

1. 确认选择的芯片型号与固件的目标芯片一致
2. BIN 固件确认起始地址正确，见 [自定义ROM地址](#自定义rom地址)

### 6. BIN 固件烧录后校验失败

确认烧录和校验使用同一个起始地址：烧录时勾选了自定义 ROM 地址，校验前不要取消勾选或修改地址。

### 7. 刚连接上一会儿就自动断开了

**自动断开** 默认启用，窗口内 10 秒无操作就会断开连接（烧录等操作进行中不计时）。在右侧 **自动断开** 卡片中延长超时时间，或点击按钮切换为 "已禁用"。

### 8. 烧录完成后程序没有运行

1. 确认勾选了 **烧录后复位**
2. BIN 固件确认烧录地址与程序链接地址一致
3. 点击工具栏的 **复位**；软件复位无效时，把复位方式改为 **硬件复位**（需接好复位线）再试
4. 断开连接后按目标板上的复位键，或重新上电

### 9. 硬件复位失败

1. 确认探针的复位线（nRST / RESET）已接到目标板的复位引脚
2. 部分探针不支持控制复位引脚，此时请改用 **软件复位**
3. 硬件复位目前仅支持 ARM 内核芯片
