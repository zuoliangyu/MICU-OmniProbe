# 数据滤波与 MATLAB 参数

串口波形可以直接执行 MATLAB 设计好的 FIR 或 IIR 滤波参数，用真实采集数据比较滤波前后的效果。应用不读取 `.mat` 文件，也不需要 MATLAB Engine 或 MATLAB Runtime。

不使用 MATLAB 时，也可以在应用内通过滤波级列表添加参数化低通、高通和带通，并按列表顺序任意级联。

## 使用流程

需要先验证滤波效果时，可在串口工作台右侧“连接”页选择“模拟数据”，将“信号预设”设为“滤波演示”并启动。该预设固定以 200 Hz 输出字段 `signal`，内容为 5 Hz 主信号叠加 40 Hz 干扰。

1. 在 MATLAB 中打开 Filter Designer：

   ```matlab
   filterDesigner
   ```

   旧版 MATLAB 也可以使用 `fdatool`。

2. 设置响应类型、阶数、截止频率和实际采样率 `Fs`，完成滤波器设计。
3. 在 MICU-OmniProbe 串口工作台打开右侧“数据”页，点击标题栏中的“图表配置”。设置弹窗会直接打开“滤波”分类，也可以通过顶部按钮切换基础、通道、性能与显示设置。
4. 选择 FIR 或 SOS，填写 MATLAB 设计时使用的 `Fs`，粘贴系数并保存。
5. 打开时域波形。滤波结果显示为通道色实线；启用“叠加显示原始曲线”后，原始数据同时显示为对比色虚线，图例中的“滤 / 原”数值也会分别着色。

滤波结果由图表、FFT、统计以及控制面板 YT/FFT 组件共享，独立图表窗口也使用同一结果，避免同一批数据在不同窗口重复处理。启用滤波后，图表“导出”菜单可以分别导出处理后数据、原始数据，或导出包含两者对应列的前后对照 CSV；未启用滤波时保持普通 CSV 导出。原始标准样本和原始日志不会被覆盖，AI 数据桥接当前仍发送滤波前的原始标准样本；关闭滤波即可立即恢复原始数据视图。

## FIR：粘贴 b 系数

MATLAB 示例：

```matlab
Fs = 1000;
b = fir1(20, 20/(Fs/2), "low");
```

在“FIR 系数 b”中可直接粘贴：

```text
[0.01 0.03 0.08 0.16 0.24 0.16 0.08 0.03 0.01]
```

应用按照零初始状态执行因果 FIR，与 MATLAB `filter(b, 1, x)` 的数据方向一致。

## IIR：粘贴 SOS 和 ScaleValues

高阶 IIR 推荐使用二阶节 SOS，避免直接使用高阶 `b/a` 带来的数值不稳定。MATLAB 示例：

```matlab
Fs = 1000;
Fc = 20;
[b, a] = butter(4, Fc/(Fs/2), "low");
[sos, g] = tf2sos(b, a);
```

把 `sos` 粘贴到“SOS Matrix”，每行依次为：

```text
b0 b1 b2 a0 a1 a2
```

可以保留 MATLAB 的方括号、空格、换行和分号。把 `g` 粘贴到“g / ScaleValues”。如果 Filter Designer 导出多个 ScaleValues，也可以全部粘贴，应用会使用它们的乘积。

## 实时中值滤波

中值滤波不使用 FIR/IIR 系数。选择“实时中值滤波”后设置奇数窗口大小即可，适合观察孤立毛刺的抑制效果。该实现使用当前样本和此前样本组成因果窗口。

## 参数化低通、高通与带通级联

在“滤波”分类中把执行函数切换为“参数化级联”，填写滤波参数使用的采样率 `Fs`，然后点击“添加滤波级”：

- 低通：设置截止频率和 Q。
- 高通：设置截止频率和 Q。
- 带通：设置中心频率和 Q，近似带宽为 `中心频率 / Q`。

每一级使用标准二阶节。左侧列表从上到下表示执行顺序，点击滤波级后可在右侧编辑参数、删除或旁路；拖动列表项可排序，也可使用参数区的上下移动按钮。频率必须大于 0 且小于 `Fs / 2`；Q 必须大于 0。常用的平坦响应 Q 可先使用 `0.7071`，再根据真实数据调整。

滤波级列表下方显示对数频率轴的幅频响应：实线代表全部启用滤波级的综合响应，虚线代表当前选中滤波级。旁路滤波级会保留参数，但不参与综合响应和实时滤波。

点击“导出参数”并选择保存位置，可得到 JSON 文件。文件同时包含：

- `sampleRateHz`：设计采样率。
- `stages`：全部节点及其顺序、类型、频率、Q 和旁路状态。
- `sosSections`：所有未旁路节点计算后的 `[b0, b1, b2, a0, a1, a2]` 系数，可直接用于实现二阶节级联。
- `scaleValues`：当前固定为 `[1]`。

级联数量不设业务级上限，但每增加一级都会增加实时计算量。出现界面刷新变慢时，应减少级数或降低同时显示的通道数量。

## 采样率提醒

MATLAB 系数和参数化级联都与配置的 `Fs` 绑定。如果当前估算采样率与参数 `Fs` 相差超过 5%，波形右下角会显示黄色提醒。此时应先确认设备采样率、串口输出节奏和图表采样率设置，再决定是否重新计算参数。
