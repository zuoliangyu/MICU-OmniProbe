## 界面概览

应用采用紧凑的 **IDE 工作台布局**，7 个工作台共用同一套界面结构：

```
┌──────┬──────────────────────────────────────────────────────────────┐
│ 模式 │ 当前工作台 / 芯片 / 探针 │ 接入指南 使用教程 设置 ⇥ 连接状态 │
│ 轨道 ├───────────────────────────────────────┬──────────────────────┤
│      │                                       │ 右侧配置检查器       │
│ 烧录 │              主工作区                 │                      │
│ RTT  │   文本、图表、终端、画布或调试面板    │ 探针 / 芯片 / 接口   │
│ 串口 │                                       │ 串口数据源 / 数据解析│
│ 日志 │                                       │ BLE 扫描 / 特征值    │
│ 蓝牙 ├───────────────────────────────────────┤                      │
│ 面板 │              输出日志                 │                      │
│ 调试 │                                       │                      │
└──────┴───────────────────────────────────────┴──────────────────────┘
```

| 区域           | 说明                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| 模式轨道       | 左侧竖排的 **烧录 / RTT / 串口 / 日志 / 蓝牙 / 面板 / 调试** 按钮，点击切换工作台                     |
| 顶栏           | 显示当前工作台名称、目标芯片、探针和连接状态，右上角提供帮助、设置和检查器开关                         |
| 主工作区       | 当前工作台的工具栏、文本区、图表区、终端、控制画布或调试面板                                           |
| 右侧配置检查器 | 烧录 / RTT / 调试显示探针与芯片设置，串口显示数据源与数据解析，蓝牙显示扫描与特征值                    |
| 输出日志       | 烧录、RTT、串口和蓝牙工作台底部的系统日志，默认折叠，点击日志栏右侧按钮展开                           |

右侧配置检查器可通过顶栏的检查器按钮收起或展开，拖动检查器左侧分隔线可以调整宽度。日志分析和控制面板没有右侧配置检查器：日志分析不需要连接设备，控制面板的组件库和组件属性位于画布区内部。

RTT、串口和 BLE 的图表区都可弹出为独立窗口。三个窗口可同时运行，切换左侧工作台不会自动收回；冻结、清空和配置操作只作用于对应来源，冻结期间后台仍继续缓存数据。

### 顶栏按钮

顶栏右上角从左到右依次是：

| 按钮       | 作用                                                                                     |
| ---------- | ---------------------------------------------------------------------------------------- |
| 接入指南   | 打开 RTT 接入指南，查看如何在固件中集成 SEGGER RTT，并可导出所需的 RTT 源文件            |
| 使用教程   | 在系统浏览器中打开当前工作台对应的在线使用教程，例如在串口工作台打开串口终端指南         |
| 设置       | 打开 [设置中心](SETTINGS_GUIDE.md)，调整主题、背景、启动工作台、默认视图和日志面板高度   |
| 检查器开关 | 收起或展开右侧配置检查器（日志分析和控制面板不显示）                                     |
| 连接状态   | 显示当前工作台的连接状态，例如 "探针已连接"、"串口未连接"；调试工作台显示调试会话状态，日志分析不显示 |

RTT 已连接但尚未启动时，顶栏还会出现黄色的 "RTT 就绪" 标签。

### 切换工作台

- 点击左侧模式轨道中的 **烧录 / RTT / 串口 / 日志 / 蓝牙 / 面板 / 调试** 按钮
- 使用快捷键 `Ctrl+1` 至 `Ctrl+6` 快速切换（见 [快捷键](#快捷键)；控制面板没有快捷键）
- 当前所在的工作台会自动保存，下次打开应用时直接进入
- 烧录或擦除进行中无法切换工作台
- 调试会话仍连接时离开调试工作台，会弹出 "确认切换模式" 对话框；切换工作台不会自动断开调试会话
- RTT 不受工作台切换影响；烧录期间会暂停 RTT 读取，烧录完成后自动重新查找控制块并继续接收

## 烧录工作台

烧录工作台用于固件烧录、擦除、校验和读取 Flash。完整说明见 [烧录工作台用户手册](FLASH_USER_MANUAL.md)。

### 基本流程

1. **选择探针**
   - 连接 DAPLink/CMSIS-DAP、J-Link 等支持的探针到 USB
   - 插入或拔出后列表自动更新，也可点击 **调试探针** 卡片右上角的刷新按钮重新检测
   - 从下拉列表选择（CMSIS-DAP 探针会显示 DAP 版本）

2. **选择芯片**
   - 在 **目标芯片** 卡片的 "搜索芯片型号..." 输入框中输入型号（如 `STM32F103C8`）
   - 从搜索结果中点击选择
   - 连接成功过的芯片会被记住：下次直接点击空白的搜索框，从 "最近连接" 列表中选择即可

3. **配置接口**（可选）
   - 展开 **接口设置** 卡片
   - 选择接口类型（SWD/JTAG）、时钟速度（默认 1 MHz）和连接模式（正常 / 复位下连接）

4. **选择固件**
   - 点击主区域固件卡片中的 **选择固件文件**，或工具栏最左侧的 "打开固件文件" 图标
   - 或直接**拖放固件文件**到窗口中
   - 支持格式：.hex, .bin, .elf, .axf, .out, .ihex

5. **连接设备**
   - 点击右侧配置检查器底部的 **连接设备** 按钮；缺少探针或芯片时，按钮上方会提示还缺哪一步

6. **烧录固件**
   - 按需在工具栏 "烧录模式" 中选择 **扇区擦除**（只擦需要写入的区域）或 **整片擦除**
   - 点击工具栏 **烧录** 按钮，在固件卡片、顶栏和输出日志中查看进度

右侧 **自动断开** 默认启用：一段时间无操作后会自动断开烧录连接，释放探针（RTT 运行时不会断开），可在该卡片中关闭或调整超时时间。

### 其他操作

| 操作 | 说明                                       |
| ---- | ------------------------------------------ |
| 擦除 | 全片擦除或自定义范围擦除                   |
| 校验 | 校验 Flash 内容与当前固件文件一致          |
| 读取 | 读取 Flash 内容并保存为 .bin 文件          |

### Windows 上使用 J-Link

安装 [SEGGER 官方 J-Link Software and Documentation Pack](https://www.segger.com/downloads/jlink/) 后，插入 J-Link，应用会自动识别并优先使用官方运行库连接，无需切换 USB 驱动。同一探针按序列号合并显示，多只探针可按序列号选择。

如果只有 USB 驱动、缺少运行库，探针仍会显示，并提示补装官方软件。安装后点击刷新即可；已有运行库更新后请重启应用。64 位应用需要 64 位运行库。便携安装无法自动发现时，可在启动应用前把 `MICU_JLINK_LIBRARY` 环境变量设为运行库的绝对路径（64 位通常是 `JLink_x64.dll`）。

官方驱动接入目前为待实机验证的初始支持，范围是 **Cortex-M + SWD**，使用现有 probe-rs 芯片定义和已导入的 Pack。当前同一应用进程仅允许一个官方 J-Link 连接；切换烧录、RTT 或调试连接前，请先断开原工作台。同一探针被 Keil、IAR 等调试会话占用时，先结束该会话即可，无需卸载或替换驱动。

已经使用 WinUSB 的 J-Link 仍可走原来的 probe-rs 通路；官方运行库接入的性能、复位连接和烧录能力尚需实机验收。

## RTT 工作台

RTT 工作台用于实时调试输出和数据可视化。完整说明见 [RTT 用户手册](RTT_USER_MANUAL.md)。

### 基本流程

0. **固件接入 RTT**
   - 固件需要先集成 SEGGER RTT 才能输出数据。文本区空状态里点"导出 RTT 源文件"即可获得所需的 4 个源文件，点"接入指南"（顶栏右上角也有同名按钮）查看完整步骤
   - 详见 [RTT 用户手册](RTT_USER_MANUAL.md#快速开始)

1. **配置探针和芯片**（同烧录工作台，右侧配置检查器与烧录工作台共用）

2. **连接设备**
   - 点击工具栏"连接 RTT"按钮建立独立 RTT 连接
   - 已在烧录工作台连接设备时可跳过这一步，RTT 直接使用烧录连接

3. **启动 RTT**
   - 按需在启动按钮旁的扫描模式按钮里选择控制块查找方式（默认自动扫描 RAM）
   - 点击"启动"按钮开始接收数据；查找控制块期间可点"取消启动"

4. **查看数据**
   - 文本日志实时显示
   - 支持搜索过滤
   - 支持通过 `更多` 切换 Hex 显示模式和导出日志，也可在文本区右键保存当前窗口全部内容为 TXT

5. **向目标发送**
   - 固件配置了下行通道时，文本区下方出现发送栏，可发送文本或 HEX

烧录或擦除期间 RTT 自动暂停读取，完成后重新查找控制块并继续接收，无需断开重连。

### RTT 工具栏

| 按钮          | 功能                                                         |
| ------------- | ------------------------------------------------------------ |
| 连接/断开 RTT | 建立或断开独立 RTT 连接                                      |
| 启动/停止     | 开始或停止数据接收；查找控制块期间显示为"取消启动"           |
| 扫描模式      | 控制块查找方式、轮询间隔、失联等待时间、核心选择和保留行数   |
| 暂停显示/继续 | 冻结文本区显示，数据继续接收，继续后补上缓存的内容           |
| 清空          | 清空所有日志                                                 |
| 视图切换      | `文本` / `分屏` / `图表`                                     |
| 搜索框        | "搜索 RTT..." 按关键词过滤文本区                             |
| 更多          | 智能启用、录制/回放会话、AI、波形/FFT、显示选项、接收分帧、触发捕获、图表配置、颜色设置和导出 |

### 图表功能

RTT 支持实时数据图表，详见 [RTT 图表功能指南](RTT_CHART_GUIDE.md)。

## 串口工作台

串口工作台用于本地串口、TCP 远程串口、UDP 数据接口和模拟数据的收发、终端交互与数据可视化。完整说明见 [串口终端指南](SERIAL_TERMINAL_GUIDE.md)。

### 基本流程

1. **选择数据源**
   - 在右侧配置检查器 `连接` 页的 **数据源** 卡片中选择 `本地串口`、`UDP 数据接口`、`TCP 远程串口` 或 `模拟数据`

2. **填写连接参数**
   - 本地串口：选择端口，确认波特率（默认 115200）；USB 串口插拔后列表自动刷新，也可点击卡片右上角的刷新按钮
   - TCP：填写主机地址和端口号；UDP：填写本地绑定地址/端口和远端地址/端口
   - 模拟数据：选择信号预设，无需硬件

3. **连接**
   - 点击配置检查器底部的 **连接**（模拟数据为 **启动模拟**），连接成功后自动开始接收
   - 工具栏 **开始 / 停止** 可暂停或恢复接收，**清空** 清除已接收的内容

4. **查看与发送**
   - 工具栏 `日志` / `终端` 切换文本显示方式，`文本` / `分屏` / `图表` 切换数据视图
   - 日志视图下在底部发送栏输入内容，按 `Enter` 或点击 **发送**；终端视图下点击终端区域后直接键入
   - 接收/发送的文本或 HEX、编码和换行符在配置检查器的 **收发设置** 卡片中调整

5. **解析数值并画图**（可选）
   - 收到数值数据后，在工具栏 `更多` 中点击 **智能启用** 自动识别格式
   - 或切换到配置检查器的 `数据` 页，选择解析模式，预览成功后点击 **应用解析**

## 日志分析工作台

日志分析工作台用于离线查看已保存的日志文件并解析成图表，不需要连接任何设备。完整说明见 [日志分析指南](LOG_ANALYSIS_GUIDE.md)。

### 基本流程

1. 点击左侧 **日志**，或按 `Ctrl+6`
2. 点击 **导入日志**，选择 UTF-8 编码的 `.log` 或 `.txt` 文件；没有日志文件时可点击 **模拟数据** 载入示例数据
3. 用 "搜索日志内容" 输入框过滤正文，或用文本区底部的定位栏按时间或关键字跳转
4. 在 **选择分析前缀** 中选择要画图的数据前缀，工作台会自动识别通道并切换到分屏视图
5. 需要调整解析方式、通道名称或单位时，点击 **高级设置**

## 蓝牙工作台

蓝牙工作台支持 BLE 中央设备和经典蓝牙 SPP 两种工作方式。完整说明见 [蓝牙用户手册](BLUETOOTH_USER_MANUAL.md)。

### BLE 基本流程

1. 点击左侧 **蓝牙**，或按 `Ctrl+4`
2. 在右侧 **工作模式** 卡片中选择 `BLE`
3. 在 **设备扫描** 卡片中点击 **扫描**，从结果列表中点击目标设备发起连接
4. 连接后程序会自动识别 Nordic UART Service（NUS）；其他设备可在 **特征值** 卡片中手动点击 **作为 Notify** / **作为 Write**
5. 点击 **开始接收 (Notify)**，数据显示在主区域；底部发送栏可向 Write 特征值写入数据

### 经典蓝牙 SPP

先在系统蓝牙设置中完成配对，然后在 **工作模式** 中选择 `经典蓝牙 SPP`，在 **SPP 虚拟串口** 卡片中点击端口右侧的 **连接**，应用会自动跳转到串口工作台并开始接收。

## 控制面板

控制面板是一块自由画布，可以把常用命令做成按钮、开关、滑块、摇杆等控件，或用数值、状态灯、曲线和 IMU 3D 显示设备数据。完整说明见 [控制面板组件](SERIAL_CONTROL_PANEL_GUIDE.md)。

### 基本流程

1. 先在串口或 RTT 工作台完成连接；需要显示数值时，同时完成数据解析
2. 点击左侧 **面板** 进入控制面板。从串口或 RTT 工作台切换过来时，数据来源会自动选为对应工作台
3. 点击 **编辑**，从左侧组件库把组件拖到画布（或直接点击组件添加），在 **组件属性** 中配置命令或通道 key
4. 点击 **运行** 锁定布局，直接操作控件

发送类组件目前只支持串口来源；面板会自动保存在本机，也可以通过 **导出** / **导入** 在其他电脑上复用。

## 调试工作台

调试工作台是面向 ARM Cortex-M 芯片的源码级调试器，可以暂停、单步、设置断点，查看源码、调用栈、寄存器、变量和内存。调试工作台不负责下载固件。完整说明见 [调试工作台用户手册](DEBUG_USER_MANUAL.md)。

### 基本流程

1. 在烧录工作台烧录带调试信息的固件，然后点击 **断开连接**，释放探针
2. 点击左侧 **调试**，或按 `Ctrl+5`
3. 在右侧配置检查器中选择探针和芯片（与烧录工作台共用）
4. 点击工具栏 **加载 ELF…**，选择本次编译生成的 `.elf` / `.axf` 文件
5. 点击工具栏 **连接**，目标会被立即暂停
6. 在源码面板行号左侧点击设置断点，再使用 **运行 / 暂停 / 步入 / 跨过 / 跳出 / 复位** 控制执行
7. 调试结束点击 **断开**，芯片继续运行

调试工作台使用独立的调试会话，与烧录工作台的 "连接设备"、RTT 工作台的 "连接 RTT" 不共用。同一探针被其他工作台占用时，请先在对应工作台断开。

## 快捷键

| 快捷键     | 功能                                                         |
| ---------- | ------------------------------------------------------------ |
| `Ctrl + 1` | 切换到烧录工作台                                             |
| `Ctrl + 2` | 切换到 RTT 工作台                                            |
| `Ctrl + 3` | 切换到串口工作台                                             |
| `Ctrl + 4` | 切换到蓝牙工作台                                             |
| `Ctrl + 5` | 切换到调试工作台                                             |
| `Ctrl + 6` | 切换到日志分析工作台                                         |
| `Ctrl + F` | 聚焦当前工作台的搜索框                                       |
| `Ctrl + L` | 清空当前工作台的数据（RTT、串口和蓝牙工作台）                |

说明：

- 光标在输入框中时，`Ctrl + 1` 至 `Ctrl + 6`、`Ctrl + L` 和 `空格` 不会触发，避免打断输入
- 烧录进行中切换工作台的快捷键不会生效
- 串口、RTT、蓝牙和日志分析文本区中的复制快捷键（`Ctrl + C`、`Ctrl + Shift + C`、`Ctrl + A`）见 [串口终端指南](SERIAL_TERMINAL_GUIDE.md) 中的 “复制日志行” 一节

## 拖放功能

### 固件拖放（烧录工作台）

支持直接拖放固件文件到烧录界面：

- 拖入时界面会显示 "释放以选择固件文件" 提示，松开即选中该固件
- 同时拖入多个文件时只使用第一个
- 支持格式：.hex, .bin, .elf, .axf, .out, .ihex

### Pack 拖放导入

支持批量拖放 .pack 文件到 Pack 管理器：

- 把 .pack 文件拖到窗口中，"Pack 管理" 卡片会自动展开并提示 "释放以导入 Pack 文件"
- 支持同时拖放多个文件

## 常见问题

### 1. 探针检测不到？

- 确认 USB 连接正常
- 尝试重新插拔探针
- 检查驱动是否安装（Windows 下 WinUSB/HID 驱动）
- Linux 用户需配置 udev 规则

### 2. 连接失败？

- 确认目标板供电正常
- 检查 SWD/JTAG 线序是否正确
- 尝试降低时钟速度
- 尝试"复位下连接"模式

### 3. RTT 没有数据？

- 确认目标固件已集成 RTT 库
- 确认调用了 `SEGGER_RTT_Init()`
- 确认目标芯片正在运行
- 详见 [RTT 用户手册](RTT_USER_MANUAL.md)

### 4. 烧录进度卡住？

- 检查 Flash 算法是否正确
- 尝试全片擦除后重新烧录
- 某些芯片可能需要导入对应的 Pack

### 5. 串口收不到数据，但其他串口助手正常？

- 在串口工作台右侧"高级设置"中开启 **DTR**，断开后重新连接
- 仍然没有数据时，再开启 **RTS** 试试（流控为"无"时才可设置）
- 树莓派 Pico、ESP32-S3、部分 STM32 USB 虚拟串口（CDC）设备通常要检测到 DTR 拉高才开始发送数据
- 同时核对波特率、数据位、校验位是否与设备一致
