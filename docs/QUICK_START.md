## 界面概览

应用采用紧凑的 **IDE 工作台布局**，烧录、RTT、串口、蓝牙、控制面板和调试共用同一套界面结构：

右侧配置检查器可通过顶栏按钮收起或展开，拖动检查器左侧分隔线可以调整宽度。控制面板的组件库和组件属性位于面板编辑区内部，不占用数据源工作台的配置检查器。底部输出日志默认折叠，需要时可从日志栏展开。

RTT、串口和 BLE 的图表区都可弹出为独立窗口。三个窗口可同时运行，切换左侧工作台不会自动收回；冻结、清空和配置操作只作用于对应来源，冻结期间后台仍继续缓存数据。

```
┌──────┬──────────────────────────────────────────────────────┐
│ 模式 │ 当前工作台 / 芯片 / 探针 / 连接状态 / 设置           │
│ 轨道 ├───────────────────────────────────────┬──────────────┤
│      │                                       │ 右侧配置区   │
│ 烧录 │              主工作区                 │              │
│ RTT  │        文本、图表、终端或调试面板     │ 探针 / 芯片  │
│ 串口 │                                       │ 接口 / 连接  │
│ 蓝牙 ├───────────────────────────────────────┤ 数据源 / BLE │
│ 面板 │     串口 / RTT 数据驱动的自由画布     │ 组件属性     │
│ 调试 │              输出日志                 │              │
└──────┴───────────────────────────────────────┴──────────────┘
```

### 模式切换

- 点击左侧模式轨道中的 **烧录 / RTT / 串口 / 蓝牙 / 面板 / 调试** 按钮
- 使用快捷键 `Ctrl+1` 至 `Ctrl+5` 快速切换
- 模式选择会自动保存

## 烧录模式

烧录模式用于固件烧录、擦除、校验等操作。

### 基本流程

1. **选择探针**
   - 连接 DAPLINK/CMSIS-DAP、J-Link 等支持的探针到 USB
   - 插入或拔出后列表自动更新，也可点击刷新按钮重新检测
   - 从下拉列表选择（会显示 DAP 版本）

2. **选择芯片**
   - 在搜索框输入芯片型号（如 `STM32F103C8`）
   - 从搜索结果中点击选择

3. **配置接口**（可选）
   - 展开"接口设置"卡片
   - 选择接口类型（SWD/JTAG）
   - 选择时钟速度（默认 1MHz）

4. **打开固件**
   - 点击"打开"按钮选择固件文件
   - 或直接**拖放固件文件**到界面
   - 支持格式：.hex, .bin, .elf, .axf, .out, .ihex

5. **连接设备**
   - 点击右侧配置区底部的"连接设备"按钮

6. **烧录固件**
   - 点击工具栏"烧录"按钮
   - 查看进度条和日志

### 其他操作

| 操作 | 说明                      |
| ---- | ------------------------- |
| 擦除 | 全片擦除或自定义范围擦除  |
| 校验 | 校验 Flash 内容与文件一致 |
| 读取 | 读取 Flash 内容到文件     |

### Windows 上使用 J-Link

安装 [SEGGER 官方 J-Link Software and Documentation Pack](https://www.segger.com/downloads/jlink/) 后，插入 J-Link，应用会自动识别并优先使用官方运行库连接，无需切换 USB 驱动。同一探针按序列号合并显示，多只探针可按序列号选择。

如果只有 USB 驱动、缺少运行库，探针仍会显示，并提示补装官方软件。安装后点击刷新即可；已有运行库更新后请重启应用。64 位应用需要 64 位运行库。便携安装无法自动发现时，可在启动应用前把 `MICU_JLINK_LIBRARY` 环境变量设为运行库的绝对路径（64 位通常是 `JLink_x64.dll`）。

官方驱动接入目前为待实机验证的初始支持，范围是 **Cortex-M + SWD**，使用现有 probe-rs 芯片定义和已导入的 Pack。当前同一应用进程仅允许一个官方 J-Link 连接；切换烧录、RTT 或调试连接前，请先断开原工作台。同一探针被 Keil、IAR 等调试会话占用时，先结束该会话即可，无需卸载或替换驱动。

已经使用 WinUSB 的 J-Link 仍可走原来的 probe-rs 通路；官方运行库接入的性能、复位连接和烧录能力尚需实机验收。

## RTT 模式

RTT 模式用于实时调试输出和数据可视化。

### 基本流程

1. **配置探针和芯片**（同烧录模式）

2. **连接 RTT**
   - 点击工具栏"连接 RTT"按钮
   - 等待连接成功

3. **启动 RTT**
   - 点击"启动"按钮开始接收数据

4. **查看数据**
   - 文本日志实时显示
   - 支持搜索过滤
   - 支持通过 `更多` 切换 Hex 显示模式和导出日志，也可在文本区右键保存当前窗口全部内容为 TXT

### RTT 工具栏

| 按钮          | 功能                                                       |
| ------------- | ---------------------------------------------------------- |
| 连接/断开 RTT | 建立或断开 RTT 连接                                        |
| 启动/停止     | 开始或停止数据接收                                         |
| 暂停/继续     | 暂停或继续显示更新                                         |
| 清空          | 清空所有日志                                               |
| 视图模式      | 仅文本/分屏/仅图表                                         |
| 更多          | 打开接入指南、智能启用、波形/FFT、显示选项、图表配置和导出 |

### 图表功能

RTT 支持实时数据图表，详见 [RTT 图表功能指南](RTT_CHART_GUIDE.md)。

## 拖放功能

### 固件拖放（烧录模式）

支持直接拖放固件文件到烧录界面：

- 拖放时会显示蓝色边框提示
- 支持格式：.hex, .bin, .elf, .axf, .out, .ihex

### Pack 拖放导入

支持批量拖放 .pack 文件到 Pack 管理器：

- 展开"Pack 管理"卡片
- 拖放 .pack 文件到卡片区域
- 支持同时拖放多个文件

## 常见问题

### 1. 探针检测不到？

- 确认 USB 连接正常
- 尝试重新插拔探针
- 检查驱动是否安装（Windows 下 WinUSB/HID 驱动）
- Linux 用户需配置 udev 规则

### 2. 连接失败？

- 确认目标板供电正常
- 检查 SWD/JTAG 线序是否正确
- 尝试降低时钟速度
- 尝试"复位下连接"模式

### 3. RTT 没有数据？

- 确认目标固件已集成 RTT 库
- 确认调用了 `SEGGER_RTT_Init()`
- 确认目标芯片正在运行
- 详见 [RTT 用户手册](RTT_USER_MANUAL.md)

### 4. 烧录进度卡住？

- 检查 Flash 算法是否正确
- 尝试全片擦除后重新烧录
- 某些芯片可能需要导入对应的 Pack

### 5. 串口收不到数据，但其他串口助手正常？

- 在串口工作台右侧"高级设置"中开启 **DTR**，断开后重新连接
- 仍然没有数据时，再开启 **RTS** 试试（流控为"无"时才可设置）
- 树莓派 Pico、ESP32-S3、部分 STM32 USB 虚拟串口（CDC）设备通常要检测到 DTR 拉高才开始发送数据
- 同时核对波特率、数据位、校验位是否与设备一致
