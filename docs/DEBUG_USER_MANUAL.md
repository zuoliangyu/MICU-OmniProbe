# 调试工作台用户手册

调试工作台是面向 ARM Cortex-M 芯片的源码级调试器：附加到正在运行的目标后，可以暂停、单步、设置断点，查看源码位置、调用栈、寄存器、全局变量和任意内存。

调试工作台**不负责下载固件**。请先在 [烧录工作台](FLASH_USER_MANUAL.md) 把固件烧进芯片，再到这里加载同一次编译生成的 ELF 文件进行调试。

## 快速开始

1. 编译固件时保留调试信息（见 [ELF 文件要求](#elf-文件要求)），在烧录工作台烧录后点击 **断开连接**
2. 点击左侧模式轨道的 **调试**，或按 `Ctrl+5`，进入调试工作台
3. 在右侧配置检查器中选择 **调试探针** 和 **目标芯片**（与烧录工作台共用同一套设置）
4. 点击工具栏 **加载 ELF…**，选择本次编译生成的 `.elf` / `.axf` 文件
5. 点击工具栏 **连接**。目标会被立即暂停，顶栏显示 "已停止 · 手动 · 0x……"
6. 在 **源码** 面板行号左侧点击，设置断点（出现红色 ●）
7. 点击 **运行**。程序执行到断点时自动停下，源码面板用 ▶ 标出当前行
8. 用 **步入 / 跨过 / 跳出** 单步执行，在 **寄存器**、**全局变量**、**观察** 面板查看数值
9. 调试结束点击 **断开**，芯片继续运行

## 界面概览

默认布局：

```
┌──────────────────────────────────────────────────────────────┐
│ 连接 │ 加载 ELF… │ 运行 暂停 步入 跨过 跳出 │ 复位 │ 视图    │
├────────┬─────────────────────────────┬───────────────────────┤
│        │                             │ 寄存器 / 全局变量 /   │
│  符号  │            源码             │ 观察 / 内存           │
│        │                             │                       │
│        ├─────────────────────────────┤                       │
│        │ 调用栈 / 断点 / 输出        │                       │

```

右侧配置检查器与其他工作台相同，用于选择探针、芯片和接口设置。调试工作台中检查器底部不提供 "连接设备" 按钮，未连接时提示 "选择探针和芯片后，点击工具栏「连接」附加调试会话"。

顶栏显示当前芯片、探针、已加载的 ELF 文件名（未加载时显示 "未加载 ELF"）和调试状态。

## 状态指示

顶栏右侧的状态标签显示调试会话的当前状态：

| 显示                       | 指示灯 | 含义                           |
| -------------------------- | ------ | ------------------------------ |
| 调试未连接                 | 红     | 没有调试会话                   |
| 目标运行中                 | 绿     | 已连接，目标正在全速运行       |
| 调试已附加                 | 绿     | 已连接，但尚未取得目标运行状态 |
| 已停止 · 原因 · 0x08000123 | 黄     | 目标已暂停，末尾为当前 PC 地址 |

停止原因：

| 原因 | 何时出现                                                                       |
| ---- | ------------------------------------------------------------------------------ |
| 手动 | 连接后自动暂停，或点击了 **暂停**                                              |
| 断点 | 目标停在已设置的断点上（运行中命中，或 **跨过** / **跳出** 途中被断点拦下）    |
| 单步 | 执行了 **步入**、**跨过** 或 **跳出**                                          |
| 未知 | 目标运行中自行停下，但停下的位置不是已设置的断点（例如固件中执行了 BKPT 指令） |

目标运行时，软件会持续检查目标是否停下。停在断点上时输出中记录 "命中断点 @ 0x……"，断点面板中该断点的命中次数加 1；因其他原因停下时记录 "目标已停止 @ 0x……"。之后自动刷新调用栈、源码、寄存器、全局变量和观察。

## 连接调试会话

调试会话是一个独立的连接，与烧录工作台的 "连接设备"、RTT 工作台的 "连接 RTT" 互不共用：

- 连接使用右侧 **接口设置** 中的接口类型、时钟速度和连接模式
- 点击 **连接** 后目标会**立即暂停**，正在运行的程序会停在当前位置
- 连接成功的芯片会加入目标芯片的 "最近连接" 列表
- 点击 **断开** 时，目标恢复运行，断点全部清除
- 调试会话不受 **自动断开** 设置影响，不会因为长时间无操作而断开

同一个探针被烧录或 RTT 连接占用时，请先在对应工作台断开，再回到这里连接。

调试会话处于连接状态时切换到其他工作台，会提示 "调试会话仍在 attach 状态……"。确认后会话保持连接，不会自动断开；其他工作台需要使用同一个探针时，请先回到调试工作台点击 **断开**。

## 加载 ELF

点击工具栏 **加载 ELF…**，选择固件的 ELF 文件。连接前后都可以加载，加载成功后输出中显示 "ELF 已加载: N 个函数 / M 个变量"。再次加载会替换之前的 ELF。

ELF 提供的信息决定了哪些功能可用：

| ELF 中的内容           | 用于                                                         |
| ---------------------- | ------------------------------------------------------------ |
| 符号表                 | 符号面板、全局变量面板、观察面板按名字查找变量               |
| DWARF 调试信息（行号） | 源码显示、源码断点、调用栈中的函数名和行号、跨过按源码行执行 |

不加载 ELF 也能连接、运行、暂停、按地址设断点、查看寄存器和内存，但没有源码和符号。

### ELF 文件要求

- **格式**：`.elf`、`.axf`、`.out`。HEX / BIN 文件没有符号和调试信息，不能用于调试
- **与芯片中的固件一致**：必须是烧进芯片的那一次编译产物。重新编译后请重新烧录，再重新加载 ELF，否则断点和源码位置会错位
- **包含调试信息**：GCC 编译时加 `-g`；Keil MDK 在 Options for Target → Output 中勾选 Debug Information。文件经过 strip 去除符号后无法使用
- **优化等级**：建议调试时用 `-O0` 或 `-Og`。优化后的代码行号会跳动，部分行无法设置断点，变量可能被优化掉
- **源文件位置**：源码面板按编译时记录的路径读取源文件，源文件需要在本机原路径下存在
- **源文件编码**：源文件需为 UTF-8 编码，单个文件不超过 4 MB

## 运行控制

| 按钮      | 可用条件 | 说明                                                    |
| --------- | -------- | ------------------------------------------------------- |
| 连接/断开 | 随时     | 附加或断开调试会话                                      |
| 加载 ELF… | 随时     | 加载符号和调试信息                                      |
| 运行      | 已停止   | 让目标全速运行，遇到断点自动停下                        |
| 暂停      | 运行中   | 立即暂停目标                                            |
| 步入      | 已停止   | 执行**一条机器指令**                                    |
| 跨过      | 已停止   | 执行到下一个源码行，遇到函数调用时整体执行完该函数      |
| 跳出      | 已停止   | 运行到当前函数返回调用者为止                            |
| 复位      | 已连接   | 按配置检查器 **接口设置** 中的 **复位方式**（软件复位 / 硬件复位）复位芯片，复位后目标重新开始运行，状态变为 "目标运行中"。硬件复位需要探针接了 nRST 引脚，且仅支持 ARM 内核 |
| 视图      | 随时     | 显示 / 隐藏面板，重置布局                               |

按钮执行期间其他按钮暂时不可用，执行完成后恢复。

### 单步说明

- **步入**按指令执行。一行 C 代码通常对应多条指令，所以按一次步入不一定换行，可能需要连按几次
- **跨过**需要已加载带行号信息的 ELF，否则等同于步入。为防止陷入长循环，一次跨过最多执行 8000 条指令；遇到很长的循环时可能停在同一行，再按一次即可继续。跨过的函数调用 5 秒内没有返回时（例如长延时函数），目标会在当时的位置暂停
- **跳出**利用返回地址实现，5 秒内没有返回时会在当时的位置暂停。在中断或异常处理函数中暂不支持跳出，会提示 "当前处于异常处理函数中（LR 为 EXC_RETURN），暂不支持 step out"，可以在调用处设断点后点击运行代替
- 跨过一个函数调用或跳出时，如果途中执行到了已设置的断点，目标会停在该断点上，状态显示 "已停止 · 断点"，并计入该断点的命中次数
- 跨过（遇到函数调用时）和跳出需要临时占用一个硬件断点，详见 [断点数量限制](#断点数量限制)

## 断点

断点使用芯片的硬件断点，需要先连接调试会话。

### 设置断点

- **源码断点**：在源码面板行号左侧的断点栏点击，出现红色 ● 表示已设置，再次点击清除。需要已加载 ELF，且该行有对应的指令
- **地址断点**：在断点面板的输入框中输入十六进制地址（如 `0x08001234`，`0x` 可省略），点击 **添加** 或按 Enter

想在某个函数入口停下，但源码面板当前没有显示该文件时，可以在符号面板的 **函数** 页找到该函数的地址，填入断点面板。Thumb 函数的符号地址末位为奇数（例如 `0x08000135`），可以原样填写，软件会自动把最低位清零，断点实际设在 `0x08000134`。

### 断点面板

| 列          | 说明                                                                                     |
| ----------- | ---------------------------------------------------------------------------------------- |
| #           | 断点编号                                                                                 |
| 地址 / 位置 | 断点地址；源码断点同时显示 `文件名:行号`                                                 |
| 命中        | 本次连接中目标停在该断点上的次数：运行或复位后命中、跨过或跳出途中被拦下都会加 1，目标停下时自动刷新 |
| 删除按钮    | 清除该断点                                                                               |

点击标题右侧的 **清空** 清除全部断点。手动暂停、单步停在断点所在的地址上不计入命中次数。

### 断点保存与恢复

- 源码断点按 ELF 文件路径自动保存。下次连接并加载同一路径的 ELF 后自动恢复，输出中显示 "已恢复 x/y 个源码断点"
- 重新编译后某些行已没有对应指令时，这些断点会被跳过
- 按地址添加的断点不会保存
- 命中次数不保存，恢复的断点从 0 开始计数
- 断开调试会话时断点全部清除

### 断点数量限制

硬件断点的数量由芯片的调试硬件决定，Cortex-M 芯片通常只有几个（常见 4~8 个，以芯片手册为准）。用满后再设置会提示 "设置断点失败"。

跨过函数调用和跳出时需要临时占用一个硬件断点，建议始终留出一个空位，否则这两个操作可能失败。

## 面板说明

### 符号

列出 ELF 符号表中的函数和变量：

- 切换 **函数 (N)** / **变量 (N)** 两个页签
- 在 **搜索...** 框中输入名字的一部分进行筛选，不区分大小写
- 每行显示符号名和地址
- 未加载 ELF 时提示 "点击工具栏「加载 ELF…」加载固件以查看符号"

### 源码

显示当前所选调用栈帧所在的源文件：

- 目标暂停后自动打开当前位置所在的文件，并滚动到当前行，用 ▶ 标出
- 面板标题显示 `文件名 : 行号`
- 红色 ● 表示该行设有断点，点击行号左侧的断点栏可设置或清除
- 在调用栈面板点击其他帧，源码面板切换到该帧的位置
- 源码为只读，不能在这里编辑，也不能手动打开其他文件

可显示的源文件类型：`.c`、`.h`、`.cc`、`.cpp`、`.cxx`、`.hpp`、`.hh`、`.hxx`、`.inl`、`.s`、`.asm`、`.inc`、`.rs`。

面板中的提示：

| 提示                                                 | 含义                                                 |
| ---------------------------------------------------- | ---------------------------------------------------- |
| 暂停后从调用栈选择一帧查看源码                       | 目标未暂停，或调用栈为空                             |
| 当前帧无源码位置（PC 不在 DWARF 行表中或未加载 ELF） | 当前位置没有行号信息，见 [常见问题](#常见问题) 第 1 条 |
| 红色错误文字（如 "源文件不存在: ……"）                | 找到了行号信息，但读取源文件失败                     |

### 调用栈

目标暂停后显示调用栈，列出 `#`、函数、位置（`文件名:行号`）和 PC：

- 第 0 帧是当前执行位置，第 1 帧是由返回地址推算出的调用者
- 当前最多显示 2 帧，更深的调用层次暂不支持。调用者一帧是推算结果，仅供参考
- 点击某一帧，源码面板跳到该帧的位置

### 断点

见 [断点](#断点)。

### 寄存器

目标暂停时自动读取（每次单步后也会重新读取），显示 PC 和内核寄存器（R0~R12、SP、LR 等）的十六进制值，下方显示 "更新于" 时间。点击 **刷新** 可手动重新读取。

目标运行中显示 "运行中，halt 后查看"。寄存器只能查看，不能修改。

### 全局变量

列出 ELF 符号表中的全局变量和静态变量：

- 在 **搜索变量...** 框中按名字筛选
- 每行显示变量名、地址和大小
- 点击变量展开，读取并以十六进制字节显示其内容，最多显示前 64 字节
- 读取过的变量收起后，行尾显示一个摘要值：大小为 1、2、4、8 字节的变量按小端整数显示（如 `0x12`、`0x1234`），更大的变量显示前 4 字节按小端解释的 32 位值，其他大小列出全部字节
- 目标每次暂停（包括单步后）自动刷新已展开的变量，也可点击 **刷新** 手动刷新；运行中显示 "需 halt 后才能读取"

当前不解析变量类型，展开后显示原始字节（结构体、数组、浮点数等需要自行换算），也不支持函数内的局部变量。

### 观察

添加想要持续关注的变量或地址，目标每次暂停（包括单步后）自动读取：

| 输入写法        | 示例                        | 说明                                                       |
| --------------- | --------------------------- | ---------------------------------------------------------- |
| 符号名          | `counter`                   | 按名字查找变量（区分大小写，需完全一致），读取该变量的大小 |
| 地址            | `0x20000010`                | 必须带 `0x` 前缀，默认读取 4 字节                          |
| 名字或地址:长度 | `flag:1`、`0x20000010:8`    | 指定读取的字节数（十进制）                                 |

- 在输入框中输入后点击 **添加** 或按 Enter；点击行尾删除按钮移除；点击标题右侧 **刷新** 可手动重新读取全部
- 单项最多读取 64 字节
- 数值按读取的长度显示（Cortex-M 为小端）：
  - 长度为 1、2、4、8 字节时，按整数显示十六进制值，后面跟十进制值；最高位为 1 时再给出有符号解释，例如 1 字节的 `0xFF = 255 / -1`
  - 其他长度列出全部字节；超过 4 字节时，第一行另外显示前 4 字节按小端解释的 32 位值
- 运行中显示 "halt 后读"；名字找不到时显示 "符号未找到: ……"
- 观察列表自动保存，重启软件后仍在

### 内存

查看任意地址的内存内容：

1. 输入起始地址（十六进制，默认 `0x20000000`）和长度（十进制字节数，默认 `256`）
2. 点击 **读取** 或按 Enter

每行显示 16 字节：地址、十六进制、ASCII（不可显示的字符显示为 `.`）。单次最多读取 64 KB。

内存面板不会自动刷新，目标状态变化后需要再次点击 **读取**。

### 输出

显示与调试相关的日志（连接、断点、单步、读取错误等），没有调试相关日志时显示全部日志：

- **自动滚动**：勾选后新日志出现时自动滚到底部
- 删除按钮（"清空日志"）会清空软件的全部日志
- 在面板中右键，选择 "保存当前窗口全部内容为 TXT" 保存调试输出

## 视图菜单与布局

点击工具栏最右侧的 **视图**：

- **面板** 列表中勾选或取消勾选，即可显示或隐藏对应面板：符号、源码、寄存器、全局变量、观察、内存、调用栈、断点、输出
- 点击 **重置布局** 恢复默认布局并显示全部面板

布局调整：

- 拖动面板标签可以移动位置、与其他面板合并为标签组，或拆分到新的区域
- 拖动面板之间的分隔线调整大小
- 点击面板标签上的关闭按钮可以关闭面板，之后可从 **视图** 菜单重新打开，面板会回到默认所在的区域
- 面板的位置、大小和显示 / 隐藏状态自动保存，离开调试工作台或重启软件后恢复为上次的排列
- 布局调乱时点击 **视图** → **重置布局** 恢复默认排列

## 常见问题

### 1. 源码不显示

源码面板显示 "当前帧无源码位置" 时：

1. 确认已点击 **加载 ELF…** 加载了 ELF，且 ELF 包含调试信息（见 [ELF 文件要求](#elf-文件要求)）
2. 确认 ELF 与芯片中的固件是同一次编译
3. 当前停在启动代码、库函数或没有调试信息的代码中时没有行号信息，设置断点后 **运行** 到自己的代码中再查看

源码面板显示红色错误时：

1. **源文件不存在**：源码按编译时记录的路径读取。工程移动过位置、换了电脑或在其他机器上编译时，路径对不上，请在本机原路径编译
2. **读源文件失败**：常见原因是源文件不是 UTF-8 编码（如 Keil 工程中含 GBK 中文注释的文件），把文件另存为 UTF-8 即可
3. **不支持读取该类型的文件**：文件扩展名不在 [支持列表](#源码) 中
4. 文件超过 4 MB 时无法显示

### 2. 点击行号旁设置断点失败

日志提示 "DWARF 行表中找不到……对应的指令地址" 时，说明这一行没有可停下的指令，常见于空行、注释、声明、被优化掉的代码。请换到相邻的有执行语句的行，或降低优化等级后重新编译烧录。

提示 "未加载 ELF" 时，先点击 **加载 ELF…**。

### 3. 断点设置提示失败

1. 硬件断点已用满，见 [断点数量限制](#断点数量限制)，删除不用的断点后再试
2. 确认调试会话已连接

### 4. 断点一直不命中

1. 确认 ELF 与芯片中的固件一致；重新编译后需要重新烧录并重新加载 ELF
2. 确认程序确实会执行到该位置
3. 按地址添加断点时，确认地址指向的是指令（函数地址可在符号面板中查到）

### 5. 跳出提示失败

- 在中断或异常处理函数中暂不支持跳出，请在调用处设断点后点击 **运行**
- 硬件断点已用满时也会失败，删除一个断点后再试

### 6. 跨过后停在了意料之外的位置

- 未加载 ELF 或当前位置没有行号信息时，跨过等同于步入，只执行一条指令
- 被跨过的函数 5 秒内没有返回（如长延时、等待外设）时，会在当时所在的位置暂停
- 一次最多执行 8000 条指令，长循环中可能停在同一行，再按一次即可

### 7. 寄存器、全局变量、观察中没有数值

这三个面板只在目标暂停时读取。目标运行中请点击 **暂停**，或设置断点后等待命中。

### 8. 调用栈只有一两帧

当前版本最多显示当前位置和推算出的调用者两帧，更深的调用层次暂不支持。

### 9. 变量值没有按类型解析

当前版本不解析变量类型。观察面板对 1、2、4、8 字节的值会同时给出十六进制和十进制整数，其他情况只显示原始字节；结构体、数组、浮点数需要按变量类型自行换算（Cortex-M 为小端）。函数内的局部变量暂不支持查看，可将需要观察的值放到全局变量中。

### 10. 连接失败

1. 确认探针没有被烧录工作台或 RTT 工作台的连接占用，先在对应工作台断开
2. 确认右侧选择的芯片型号正确，目标板已供电
3. 在 **接口设置** 中降低时钟速度，或把连接模式改为 **复位下连接**
4. 其他排查方法见 [烧录工作台用户手册](FLASH_USER_MANUAL.md#常见问题)
