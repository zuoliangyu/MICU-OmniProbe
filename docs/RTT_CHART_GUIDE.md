# RTT 图表与波形功能指南

## 功能概述

RTT 图表把固件输出的数值实时绘制成波形或图表，适合日志可视化，也适合实时调试数值流。图表解析在后台进行，与文本区互不影响：关闭图表视图后数据仍继续解析和缓存。

支持能力：

- **视图**：工具栏的 `文本` / `分屏` / `图表` 切换；分屏时可选上下或左右排列
- **解析模式**：自动、分隔符、JSON、KV (key=value / key:value)、正则表达式，以及字节流模式：通用二进制协议、JustFloat / VOFA RawData、CAN / SLCAN
- **图表类型**：
  - 波形示波器（可在时域和 FFT 频谱之间切换）
  - 折线图
  - 柱状图
  - 散点图（按时间）
  - XY 散点图，见 [RTT XY 散点图](RTT_XY_SCATTER_GUIDE.md)
- **实时交互**：冻结 / 恢复跟随、左键拖拽平移、滚轮缩放 Y 轴、`Shift + 滚轮` 缩放 X 轴、右键或点击 `自适应` 重置视图、悬停查看数值
- **分析与导出**：统计（最小值 / 最大值 / 平均值 / 当前值）、数据滤波（FIR / IIR / 中值 / 参数化级联）、CSV 数据导出、PNG 图像导出、[触发捕获](TRIGGER_CAPTURE_GUIDE.md)
- **独立窗口**：整个图表工作台可弹出为独立窗口，方便在副屏持续观察；RTT、串口和 BLE 的独立窗口可同时打开，切换主工作台不会自动收回，控制操作按数据源隔离

## 推荐用法

### 适合用波形示波器的场景

- RTT 输出连续采样值，例如电压、电流、速度、角度
- 想看最近一段时间的波形变化趋势
- 想快速切换到 FFT 查看主频、谐波和噪声分量

### 适合用普通图表的场景

- 只需要看趋势，不需要频谱分析
- 数据是结构化报文或状态数据
- 需要 XY 关系图而不是时间轴波形

## 快速开始

### 1. 启用图表

1. 连接 RTT 并启动采集，让文本区先收到几行数值数据
2. 打开工具栏的 `更多`，在 `工作流` 中点击 `智能启用`，或在 `配置` 中点击 `图表配置`
3. 用 `图表配置` 时：打开基础页右上角的总开关，选择解析模式和图表类型（建议 `波形示波器`），点击 `保存配置`。如果接收缓冲区已有数据且通道为空，配置窗口会先按当前解析模式预建通道；`自动` 模式会同时识别数据格式
4. 切换到 `图表` 或 `分屏` 视图
5. 点击图表工具栏的 `通道`，可查看当前解析字段并把字段加入曲线
6. 在波形底部拖动 `X 轴缩放` 条调整可视范围；缓冲区上限、可视点数和采样率在 `图表配置 → 性能与采样` 中精确输入

图表尚未配置或还没有数据时，图表区中央的提示会指向 `更多 → 智能启用` 和 `更多 → 图表配置` 这两个入口。

### 2. 用"智能启用"自动识别

当 RTT 已经收到几行数值数据后（没有数据时按钮不可用）：

1. 打开工具栏的 `更多`，点击 `智能启用`
2. 程序分析最近 20 行文本（设置了 "数据帧前缀" 时只看带前缀的行），依次判断以下格式：

| 识别结果 | 数据示例 | 自动配置 |
| -------- | -------- | -------- |
| 单数值 | `123` | 分隔符模式，通道 `value`（数值），波形示波器 |
| 序号 + XY | `20,4997.32,122954.44`（第 1 列为递增整数） | 分隔符模式，通道 `seq`（隐藏）、`x`、`y`，XY 散点图 |
| XY 两列 | `12,-35` | 分隔符模式，通道 `x`、`y`，XY 散点图 |
| JSON | `{"temp":25.5,"rpm":1450}` | JSON 模式，每个数值字段一个通道，波形示波器 |
| 键值 | `temp=25.5 rpm=1450` | KV 模式，每个稳定出现的字段一个通道，波形示波器 |
| 多列 CSV | `1.2,3.4,5.6` | 分隔符模式，通道 `field1`、`field2`…，波形示波器 |

3. 识别成功后会启用图表、覆盖原有通道和解析模式，当前是 `文本` 视图时自动切到 `分屏`，输出日志会显示识别结果和通道数
4. 置信度低于 50% 时不修改配置，日志提示 "无法识别数据格式"，此时请手动配置

分隔符支持逗号、制表符、空格和分号，会自动选出最合适的一种；识别为制表符时，图表配置中的分隔符显示为 `\t`。数值需为普通十进制写法（如 `-12`、`3.14`），科学计数法不参与识别。

### 3. 时域 / 频域切换

有两种进入方式：

- 方式一：从 RTT 工具栏的 `更多 → 工作流` 中点击 `波形` 或 `FFT`。会自动启用图表解析、把图表类型切为 `波形示波器`，当前是 `文本` 视图时切到 `分屏`
- 方式二：当图表类型为 `波形示波器` 时，在图表工具栏里切换 `时域 / FFT`

`更多` 中当前打开的 `波形` 或 `FFT` 会保持点亮；再次点击已点亮的按钮会收起图表并切回 `文本` 视图。收起只改变布局，数据仍在后台解析和缓存；如需停止解析，请关闭图表配置中的总开关。

说明：

- 采样率优先使用配置中的 `采样率 (Hz, 0=自动)`
- 填写为 `0` 时，程序会按数据到达时间自动估算
- 时域波形会按样本等间隔重建横轴，避免 RTT 批量到达时出现竖线、折返和乱跳
- FFT 使用最近的 `FFT 窗口大小` 个点，默认 `1024`

## 图表工具栏

图表区顶部的工具栏：

| 按钮 | 说明 |
| ---- | ---- |
| 冻结 / 恢复跟随 | 冻结后保留当前画面用于观察，后台继续解析和缓存；点击 `恢复跟随` 追上最新数据。RTT 工作台中焦点不在输入框时按 `Space` 也可切换。触发捕获冻结时显示的是捕获画面，见 [触发捕获](TRIGGER_CAPTURE_GUIDE.md) |
| 清空数据 | 清空图表缓存、解析统计和触发状态，不影响文本区 |
| 时域 / FFT | 仅波形示波器显示 |
| 统计 | 每条可见曲线的最小值、最大值、平均值和当前值 |
| 通道 | 打开 "数据通道" 弹窗：查看每个字段的实时值、修改显示名称、用开关控制曲线显隐；尚未入图的字段点击 `加入` 即可参与绘制 |
| 导出 | `导出 CSV 数据` 导出当前图表数据；`导出 PNG 图像` 导出当前画面。开启滤波后 CSV 分为处理后、原始和前后对照三种 |

工具栏右侧显示 `已冻结` 标记（触发捕获冻结时为 `已冻结 · 触发捕获`）和 `解析 xx%`（解析成功率）。

图表区标题栏右侧的 `独立窗口` 可把图表工作台弹出到单独窗口：

- 主界面图表区会显示 "图表工作台已在独立窗口打开"，提供 `定位窗口` 和 `收回主界面`
- 独立窗口中可以 `收回主窗口` 或 `关闭`
- 主窗口继续负责接收数据，独立窗口按 `独立窗口刷新间隔 (ms)` 同步画面，请保持主窗口开启

## 配置示例

### 示例 1：单个数值波形

固件输出：

```c
SEGGER_RTT_printf(0, "%d\n", adc_value);
```

推荐配置：

- 解析模式：自动 或 分隔符
- 图表类型：波形示波器
- 通道：键 `value`，列号 `0`，显示名称 `电压`

> `SEGGER_RTT_printf` 不支持 `%f`，浮点数请放大成整数输出，或拆成整数和小数部分。

### 示例 2：CSV 多通道波形

固件输出：

```c
SEGGER_RTT_printf(0, "%d,%d,%d\n", ia, ib, ic);
```

推荐配置：

- 解析模式：分隔符
- 分隔符：`,`
- 图表类型：波形示波器
- 通道：
  - 键 `ia`，列号 `0`，显示名称 `A相`
  - 键 `ib`，列号 `1`，显示名称 `B相`
  - 键 `ic`，列号 `2`，显示名称 `C相`

### 示例 3：JSON 结构化输出

固件输出：

```c
SEGGER_RTT_printf(0, "{\"temp\":%d,\"rpm\":%d,\"current\":%d}\n", temp, rpm, current);
```

推荐配置：

- 解析模式：JSON
- 图表类型：波形示波器 或 折线图
- 通道（留空时自动提取全部数值字段）：
  - 键 `temp`，显示名称 `温度`
  - 键 `rpm`，显示名称 `转速`
  - 键 `current`，显示名称 `电流`

### 示例 4：XY 数据

固件输出：

```c
SEGGER_RTT_printf(0, "%d,%d\n", angle, torque);
```

推荐配置：

- 解析模式：分隔符
- 图表类型：XY 散点图
- 通道：键 `x`，列号 `0`，角色 `X`；键 `y`，列号 `1`，角色 `Y`，显示名称 `扭矩`

### 示例 5：日志与数值混合输出

同一通道既有普通日志又有数值时，给数值行加一个固定前缀：

```c
SEGGER_RTT_printf(0, "[INFO] 电机启动\r\n");
SEGGER_RTT_printf(0, "P:%d,%d\r\n", speed, current);
```

在图表配置的 `数据帧前缀（可选）` 中填写 `P:`。只有以 `P:` 开头的行参与解析，解析前会去掉前缀；文本区仍完整显示所有行。

## 波形交互说明

在 `波形示波器` 模式下：

- **左键拖拽**：左右拖动平移时间轴或频谱视图，上下拖动平移 Y 轴
- **滚轮**：缩放 Y 轴
- **Shift + 滚轮**：缩放 X 轴
- **X 轴缩放条**：拖动底部滑条缩放时域或频域的 X 轴，与 `Shift + 滚轮` 作用相同，右侧显示当前倍数
- **右键 / 自适应**：恢复 X/Y 自动范围；处于自动范围时 `自适应` 按钮保持点亮
- **悬停**：查看当前时刻或当前频点的数值（需开启 `显示 Tooltip`）
- **图例**：画面上方显示每条曲线的名称和最新值（需开启 `显示图例`）
- **连接方式**：在图表配置的 `显示` 页选择 `直线连接` 或 `平滑曲线`；仅影响时域波形的绘制效果

底部控制栏依次显示：

| 项目 | 说明 |
| ---- | ---- |
| Δt | 当前采样间隔 |
| 采样 Auto | 点亮表示按数据到达时间自动估算采样率；手动填写过采样率时点击可恢复自动 |
| 缓冲 | 当前缓存点数 / 最大数据点数 |
| 绘制 | 本次绘制的点数 / 可视点数上限（`全部` 表示不限制） |
| X/div 或 F/div | 每格对应的时间或频率 |
| 通道颜色 | 当前可见曲线的颜色和名称 |

数据点太少时画面中央显示 "等待足够的数据样本…"。

在 `FFT` 模式下：

- X 轴显示频率（Hz）
- Y 轴显示幅度（dB）；Hann 窗已做幅值补偿，单位正弦在频点对齐时峰值约为 `0 dB`
- 多个系列会叠加显示，便于比较频谱差异

折线图、柱状图和散点图的横轴是从第一点起算的相对时间（秒），底部有一条范围拖动条，拖动两端可以只看其中一段。

## 配置项说明

图表配置窗口标题为 `RTT 图表配置`，分为 `基础`、`通道`、`性能与采样`、`显示`、`滤波` 五页，修改后点击 `保存配置` 生效，`取消` 放弃修改。

### 基础

- **总开关**：基础页右上角。关闭后停止结构化数据解析；原始日志仍继续接收
- **解析模式**：

| 模式 | 说明 |
| ---- | ---- |
| 自动 | 依次尝试 JSON → 正则 → KV → 分隔符，任意一种成功即停止 |
| 分隔符 | 按分隔符切列，每条通道用 `列号` 指定读取第几列（从 0 开始） |
| JSON | 整行作为 JSON 解析，按通道的键取数值字段；通道留空时自动提取全部数值字段 |
| KV (key=value / key:value) | 提取行内所有 `key=value` 或 `key:value` 数值对；通道留空时全部保留，否则只保留命中的键 |
| 正则表达式 | 用命名捕获组提取数值，如 `(?<temp>\d+\.\d+)`，通道的键必须与捕获组同名。可填写 `标志`，并在 `数据样本` 中粘贴一条日志，下方立即显示能否提取以及提取到的数值 |
| 通用二进制协议 | 按协议设计器的配置从原始字节流分帧、匹配消息、校验 CRC 并解码字段 |
| JustFloat / VOFA RawData | 解析 little-endian float32 数组，以 `00 00 80 7F` 结束；通道留空时按首帧自动生成 |
| CAN / SLCAN | 解析 SLCAN 经典 CAN 与 CAN FD 帧；选中后在基础页下方的 `Payload 信号` 中添加信号或 `导入 DBC`，每个信号成为一条通道 |

字节流模式直接处理每个 RTT 通道的原始字节，不受 [接收分帧](RTT_USER_MANUAL.md#接收分帧) 影响，各通道的数据分别解析。各模式的数据格式详见 [输入数据解析格式](DATA_FORMAT_GUIDE.md)。

CAN / SLCAN 适合固件把 CAN 报文按 SLCAN 文本格式（如 `t1238AABBCCDDEEFF0011`）经 RTT 转发出来的场景。RTT 没有 CAN 适配器，因此这里只配置信号，不显示波特率、负载统计和适配器初始化设置；帧 / 负载 / 节点 / 发送等 CAN 专用视图仅在串口工作台提供。

- **图表类型**：波形示波器、折线图、柱状图、散点图（按时间）、XY 散点图
- **数据帧前缀（可选）**：仅文本解析模式可用。只解析以此前缀开头的文本，匹配后会剥离前缀，原始日志仍完整显示
- **分隔符**：分隔符模式下填写，例如 `,`、`;` 或空格。看不见的字符用转义写法：`\t`（制表符）、`\r`、`\n`、`\\`（反斜杠本身）、`\xHH`（十六进制字节，如 `\x1F`）

### 通道

一行一个通道，统一管理字段名、显示样式和 X 轴：

| 列 | 说明 |
| -- | ---- |
| 键 | 字段名，对应 JSON / KV 的键、正则的捕获组名或分隔符模式下的列名 |
| 列号 | 分隔符、自动和 JustFloat 模式显示（JustFloat 下为 `浮点序号`），表示读取第几个值，从 0 开始 |
| 显示名称 | 图例、统计和通道弹窗中显示的名称 |
| 单位 | 例如 `℃`、`Hz`，显示在数值后面 |
| 颜色 | 曲线颜色 |
| 角色 | 仅 XY 散点图显示，`X` 或 `Y`，最多一个 `X` |
| 显示 | 是否绘制该曲线 |
| ↑ ↓ / 删除 | 调整顺序或删除 |

右上角 `添加` 新增通道，`重置通道` 清空全部通道。已有通道不会被缓冲区自动识别结果覆盖；通道为空时，打开配置窗口会读取最近的接收数据预建通道：`自动` 模式自动选择格式，手动选择的模式则保持不变并按该模式提取字段。

### 性能与采样

| 设置项 | 默认值 | 说明 |
| ------ | ------ | ---- |
| 最大数据点数 | 4000 | 缓存长度，范围 100~200000，建议 `1000 ~ 4000` |
| 可视点数 (0=自动) | 600 | 限制单次绘制的点数，超过时按包络抽稀，保留峰值；`0` 表示绘制全部缓存 |
| 独立窗口刷新间隔 (ms) | 33 | 独立窗口同步画面的间隔，最小 16 |
| 采样率 (Hz, 0=自动) | 0 | 时域横轴和 FFT 频率轴使用，`0` 表示按数据到达时间自动估算 |
| FFT 窗口大小 (32-4096) | 1024 | 参与 FFT 的最近点数 |

### 显示

- **波形连接方式**：仅波形示波器显示。`直线连接` 保留采样点之间的线性变化，`平滑曲线` 让趋势更易观察；默认使用直线连接。平滑只改变屏幕上的连接方式，不修改原始采样点和悬停数值；FFT 频谱始终使用直线连接
- **显示网格**、**显示图例**、**显示 Tooltip**：默认开启
- **启用动画**：默认开启，作用于折线图、柱状图和散点图的绘制动画

### 滤波

与串口工作台使用同一套数据滤波：

- **启用数据滤波**：作用于波形、FFT 和图表统计；文本区的原始输出不变
- **执行函数**：`IIR · SOS + ScaleValues`、`FIR · b 系数`、`实时中值滤波`、`参数化级联`（可逐级设置低通 / 高通 / 带通的频率与 Q，并预览频响）
- **滤波采样率 Fs**：中值滤波以外需要填写，应与固件实际输出频率一致
- **叠加显示原始曲线**：在滤波结果下方同时画出原始曲线，便于对照

开启后，图表工具栏 `导出` 中可选择 `导出处理后数据`、`导出原始数据` 或 `导出前后对照`；[触发捕获](TRIGGER_CAPTURE_GUIDE.md) 按滤波后的数值判断。各参数的含义和 MATLAB 导出方法见 [数据滤波与 MATLAB 参数](MATLAB_FILTER_GUIDE.md)。

## 常见问题

### 图表没数据

检查：

1. 图表配置的总开关是否已打开
2. 文本区是否已经收到与配置格式匹配的数据；可以先试 `智能启用`
3. 分隔符模式下通道的 `列号` 是否正确，JSON / 正则模式下通道的键是否和字段名一致
4. 设置了 `数据帧前缀` 时，数据行是否以该前缀开头
5. 图表工具栏的 `解析 xx%` 是否很低，或 `通道` 弹窗里能否看到实时值
6. 曲线是否被隐藏：`通道` 弹窗中打开对应开关

### FFT 看起来不对

检查：

1. 采样率是否正确；固件按固定周期输出时建议在 `性能与采样` 中填写实际采样率
2. 数据是否足够稳定
3. FFT 窗口大小是否合适
4. 数据间隔是否过于抖动

### 图表卡顿

建议：

1. 把最大数据点数调低到 `1000 ~ 2000`
2. 适当调小可视点数
3. 降低固件输出频率
4. 关闭不需要的曲线
5. 冻结图表后再观察当前画面
