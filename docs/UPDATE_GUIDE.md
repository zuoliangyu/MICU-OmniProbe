# 应用自动更新

MICU-OmniProbe 可以从 GitHub Releases 检测新版本，下载后自动安装并重启。

## 检查更新

- **自动检查**：每次启动应用时会在后台静默检查一次。没有新版本时不会打扰你。
- **手动检查**：打开 **设置中心**，在顶部“应用信息”区域点击 **检查更新**。检查结果会写入日志面板。

## 安装更新

发现新版本时会弹出“发现新版本”对话框，显示当前版本、最新版本和本次更新内容。

1. 点击 **立即更新** 开始下载，对话框中会显示下载百分比；如果服务器未提供文件总大小，则显示已下载大小和动态加载状态。
2. 下载完成后显示“正在安装更新”并自动安装。Windows 会启动安装程序并退出应用，安装完成后重新打开；其他平台在安装完成后约 2 秒重启。
3. 如果暂时不想更新，点击 **稍后更新** 关闭对话框，下次启动时会再次提示。

> 更新会重启应用。开始更新前，请先导出或保存尚未保存的采集数据和会话记录。

## 常见问题

### 检查更新失败

- 确认电脑可以访问 GitHub（`github.com`）。公司网络或代理可能会拦截。
- 查看日志面板中的“检查更新失败”详细信息。
- 也可以直接到 [Releases 页面](https://github.com/zuoliangyu/MICU-OmniProbe/releases/latest) 手动下载最新安装包。

### 下载或安装失败

- 网络中断后重新点击 **检查更新** 再试一次。
- 如果更新对话框仍然打开，也可以再次点击 **立即更新**，下载进度会重新开始。
- Windows 上如果安装程序被安全软件拦截，请允许后重试，或手动下载安装包覆盖安装。
