# AI 数据桥接与可视化调参指南

MICU-OmniProbe 可以把串口文本行和解析得到的原始标准样本，以实时 NDJSON 数据流提供给本机 AI 工具。AI 与文本区、波形和 FFT 来自同一批输入，但数值样本当前不应用页面中的滤波配置，因此可以保留原始数据进行分析和调参。

## 开始使用

1. 进入串口工作台，连接设备并点击“开始”。
2. 从工具栏“更多”中点击“智能启用”或打开图表配置，确认通道、单位和采样率正确。
3. 打开串口工具栏的“更多”，在 AI 数据桥接区域设置端口（默认 `8765`）并启动。
4. 启动后服务只监听 `127.0.0.1`，不会向局域网暴露。
5. 点击“复制监听命令”，在项目根目录执行复制出的命令。

持续查看标准数据流：

```bash
python skills/micu-omniprobe-ai/scripts/client.py watch --port 8765
```

采集 5 秒并生成适合 AI 阅读的统计摘要：

```bash
python skills/micu-omniprobe-ai/scripts/client.py snapshot --port 8765 --seconds 5
```

摘要包含样本数、采样率、每个通道的最小值、最大值、均值、标准差和最新值，以及采集窗口内最近 200 行串口文本。即使没有可解析的数值，只要收到了文本行，采集也会成功。

## 数据来源

AI 桥接复用串口数据解析，支持现有的：

- JSON 数值字段
- CSV / 自定义分隔符
- `key=value`
- 正则表达式
- JustFloat / VOFA RawData
- 自动识别

文本行不依赖图表解析，包含时间戳、`rx` / `tx` 方向和原文，因此 `no_signal`、错误原因和结论等非数值诊断内容也能交给 AI。单行超过 16384 个字符时会截断，并以 `truncated: true` 标记。

数值样本仍依赖数据解析。解析未启用或没有解析出有效数值时，客户端不会收到 `samples` 消息，但仍可收到 `text` 消息。解析独立于当前打开的展示视图；需要分析波形时，可先确认解析成功数持续增加。AI 当前发送滤波前的原始标准样本，页面滤波不会改变桥接数据。

服务端输出两种数据消息：

- `type: "samples"`：解析后的数值通道与样本。
- `type: "text"`：文本区对应的串口行，字段为 `timestamp`、`direction`、`text` 和 `truncated`。

`sampleRateHz` 为 `0` 表示没有配置采样率。串口数据可能成批到达，AI 不应把每批数据的到达间隔当作真实采样周期；需要频率、相位或 FFT 分析时，请在图表配置中填写实际采样率。

## 允许 AI 写入参数

桥接启动后默认为只读。只有需要执行调参命令时，才打开“允许 AI 写串口”。

发送文本命令：

```bash
python skills/micu-omniprobe-ai/scripts/client.py write --port 8765 --text "kp=0.20" --line-ending lf
```

支持 `none`、`lf`、`crlf`、`cr` 四种换行，单条命令最多 1024 字节。命令成功写入串口后会返回包含写入字节数的 ACK；未授权、串口未连接或命令不合法时会返回错误。

建议采用以下调参顺序：

1. 保存当前安全参数和恢复方法。
2. 采集固定时间窗，记录调参前指标。
3. 一次只改一个参数，并限制合法范围和步长。
4. 发送前确认完整命令。
5. 调整后采集相同时长的数据进行对比。
6. 波形失稳、饱和或通信异常时立即停止，并恢复上一个安全值。

不用时关闭写权限；停止桥接也会自动关闭写权限。

## Codex Skill

项目提供 `skills/micu-omniprobe-ai`。将该目录安装到 Codex Skills 后，可以用 `$micu-omniprobe-ai` 要求 AI 观察串口数据、比较调参前后指标，并在用户确认后执行受控写入。

串口工具栏的“更多”菜单提供“Skill”入口，可直接复制 Skill 的 GitHub 链接，或复制已经带上当前桥接端口和安全要求的安装文案，再粘贴给用户自己的 AI。软件不会自动修改任何 AI 工具的安装目录。

Skill 不会绕过应用的写权限。没有参数边界、恢复值或明确确认时，它只应给出建议。

## 常见问题

**客户端能连接但没有样本**

- 确认串口正在接收。
- 如果能看到 `textLines` 但 `sampleCount` 为 `0`，说明文本桥接正常，只是没有解析出数值。
- 确认数据解析已启用且解析成功数持续增加。
- 检查通道字段和数据格式是否匹配。

**提示端口占用**

换一个 `1024-65535` 范围内的端口，或关闭正在使用该端口的本机程序。

**丢弃批次持续增长**

表示客户端读取速度跟不上数据产生速度。桥接会丢弃该客户端的旧批次，确保不会拖慢串口和界面。可降低设备输出频率、减少通道，或缩短单次观察时间。

**写命令被拒绝**

确认串口已连接，并在“AI”面板中显式打开“允许 AI 写串口”。每次重新启动桥接后都需要重新授权。
