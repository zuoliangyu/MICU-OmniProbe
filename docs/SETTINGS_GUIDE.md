# 设置中心使用指南

`设置中心` 是 MICU-OmniProbe 的全局偏好入口，用来统一管理背景显示、主题方案、启动工作台、RTT / 串口默认视图、日志面板高度和应用信息。当前设置中心按 `外观`、`偏好`、`帮助` 三个页签分组，默认打开 `外观` 页，并在页签上方固定显示 `应用信息`。

## 入口位置

1. 打开应用主界面
2. 在顶栏右上角点击 `设置`
3. 设置中心默认会进入 `外观` 页，对话框标题下方显示当前配色名称
4. 按需切换到 `偏好` 或 `帮助` 页查看对应内容

顶栏 `设置` 左侧还有两个帮助按钮：

- `接入指南`：打开 RTT 接入指南，查看如何在固件中集成 SEGGER RTT
- `使用教程`：在系统浏览器中打开当前工作台对应的在线使用教程

## 当前可配置内容

### 1. 背景显示（外观页）

`外观` 页首屏的 `背景显示` 区域用来设置主界面背景：

- `主题默认背景`：跟随当前主题的渐变色
- `自定义图片`：使用本地图片作为背景

`图片资源` 区域：

- `当前图片` 显示已选图片的文件名，未选择时显示 `未选择图片`
- 点击 `选择` 从本地选择一张图片，支持 png、jpg、jpeg、webp、bmp；选择后自动切换为 `自定义图片`
- 点击 `默认` 清除已选图片，并把背景方式和透明度一起恢复为默认值（未选择图片时此按钮不可用）
- `图片透明度` 滑块范围 0%–100%，默认 42%，只影响背景图片本身，不会影响面板和文字的可读性

选择完成后立即生效，并会在下次启动时保留。图片文件被移动或删除导致无法加载时，应用会退回主题默认背景，并在输出日志中提示。

### 2. 主题方案（外观页）

主题方案位于 `外观` 页，默认折叠显示，避免打开设置时被主题卡片占满首屏。点击 `主题方案` 标题展开后，可在以下内置配色中切换：

| 主题       | 副标题           |
| ---------- | ---------------- |
| 默认石墨   | Neutral Graphite |
| 樱花粉     | Soft Petals      |
| 海洋蓝     | Clear Tide       |
| 水色玻璃   | Clear Water      |
| 森林绿     | Moss Grove       |
| 暮光紫     | Soft Dusk        |
| 琥珀橙     | Warm Sunset      |
| 薄荷青     | Fresh Breeze     |
| 玫瑰木红   | Muted Bloom      |

当前使用的主题卡片右上角会标出 `当前`。切换后立即应用到当前界面，并在下次启动时保留。

### 3. 启动进入（偏好页）

可以设置应用打开时进入的工作台：

- `烧录工作台`
- `RTT 工作台`
- `串口工作台`
- `日志分析工作台`
- `蓝牙工作台`
- `控制面板`
- `调试工作台`

选择后会立即切换到该工作台。应用每次都会打开到上次所在的工作台，因此平时通过左侧模式轨道或快捷键切换工作台，这一项也会随之更新。

### 4. RTT 默认视图（偏好页）

可以设置 RTT 工作台的展示方式：

- `仅文本`
- `分屏`
- `仅图表`

该选项与 RTT 工具栏中的 `文本` / `分屏` / `图表` 切换是同一个设置，在任一处修改都会同步并保存。如果你经常一边看原始日志一边看波形，建议选择 `分屏`。

### 5. RTT 波形默认域（偏好页）

可以设置 RTT 进入波形工作流时打开的观察域：

- `Time 波形`
- `FFT 频谱`

说明：

- `Time 波形` 适合看原始采样变化趋势
- `FFT 频谱` 适合看主频、谐波和噪声分布

### 6. 串口默认视图（偏好页）

可以设置串口工作台的展示方式：

- `仅文本`
- `分屏`
- `仅图表`

与串口工具栏中的 `文本` / `分屏` / `图表` 切换同步。如果串口数据既要看原始文本又要做图表分析，建议选择 `分屏`。

### 7. 串口波形默认域（偏好页）

可以设置串口进入波形工作流时打开的观察域：

- `Time 波形`
- `FFT 频谱`

串口与 RTT 共用同一套波形 / FFT 工作流，因此使用习惯可以保持一致。

### 8. 日志面板高度（偏好页）

烧录、RTT、串口和蓝牙工作台底部有 `输出日志` 面板，高度支持三种调整方式：

- 展开后直接拖动日志面板顶部的分隔条
- 使用日志栏右上角按钮一键折叠 / 展开
- 在设置中心中通过滑块精确调整，范围 80–600 px，默认 104 px

应用会自动记住你最后一次设置的高度。

底部日志默认保持折叠，避免占用主工作区；展开后仍会使用已保存的高度。

日志栏右上角另有 `导出日志为 .txt` 和 `清空日志` 按钮。在日志内容区右键，也可将当前全部日志保存为 TXT；调试工作台的 "输出" 面板也支持相同操作。

### 9. 应用信息与作者

页签上方的 `应用信息` 会始终显示当前版本和 `检查更新` 按钮，检查与安装流程见 [自动更新](UPDATE_GUIDE.md)。点击 `关于作者` 可查看作者 Bilibili 主页和项目 GitHub 仓库链接；切换到任意页签时，这些入口都会保持可见。

### 10. 帮助与在线文档

`帮助` 页提供 `在线文档` 按钮和常用功能速查：

- `在线文档`：在系统浏览器中打开完整用户文档首页，查看快速入门、RTT、串口、图表、蓝牙和其他功能说明；需要直接打开当前工作台的教程时，使用顶栏的 `使用教程`
- `波形 / FFT`：如何打开时域或频域图表
- `智能启用`：收到数值流后自动识别单值、CSV、XY 或 JSON
- `快捷键`：工作台切换、搜索、清空等全局快捷键，完整列表见 [快速入门](QUICK_START.md#快捷键)

## 推荐使用方式

### 偏向 RTT 调试

建议这样设置：

- 背景显示：按个人喜好选择 `主题默认背景` 或自定义图片
- 启动进入：`RTT 工作台`
- RTT 默认视图：`分屏`
- RTT 波形默认域：`Time 波形` 或 `FFT 频谱`

这样打开应用后就能更快进入 RTT 采集和图表分析流程。

### 偏向串口采集

建议这样设置：

- 背景显示：如果需要更强的识别感，可以选择一张低透明度背景图
- 启动进入：`串口工作台`
- 串口默认视图：`分屏`
- 串口波形默认域：按你的数据类型选择 `Time 波形` 或 `FFT 频谱`

### 偏向日志观察

如果你主要看文本输出，建议：

- 背景显示优先使用 `主题默认背景`，避免图片干扰阅读
- RTT / 串口默认视图都设置为 `仅文本`
- 日志面板高度适当调高，方便同时查看系统日志

## 与波形 / FFT 的关系

设置中心只决定默认偏好，不会限制你在工作台中临时切换：

- RTT 和蓝牙工具栏的 `更多` 菜单里可直接打开 `波形` 或 `FFT`；串口工具栏切换到 `分屏` 或 `图表` 后，在图表工具栏切换时域 / FFT
- `更多` 中的 `智能启用` 可以根据收到的数据自动识别图表配置

也就是说：

- 设置中心决定"默认打开成什么样"
- 工具栏决定"当前这次要怎么分析"

## 常见问题

### 改完设置后需要重启应用吗？

不需要。设置中心里的选项都会立即生效并自动保存，下次打开应用时恢复。

### 调整日志面板高度后会丢失吗？

不会。高度会自动保存，下次打开应用时会恢复。

### 自定义背景图片会影响界面文字吗？

不会。透明度调节只作用于背景图片层，前景卡片和文字样式保持不变。

### 为什么切回默认背景后图片不见了？

这是预期行为。切回 `主题默认背景` 后，应用会恢复主题默认背景，已选图片仍会保留，再切回 `自定义图片` 即可重新显示；如果你点击了 `默认`，已选图片会被清除，透明度也会恢复为 42%。

### RTT 和串口为什么都能设置 FFT？

因为两者都支持对数值流做波形和频谱分析。只要数据格式适合，RTT 和串口都可以走同一套图表分析流程。
