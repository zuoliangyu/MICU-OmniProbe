# 设置中心使用指南

`设置中心` 是 MICU-OmniProbe 的全局偏好入口，用来统一管理界面主题、背景显示、启动工作台、RTT / 串口默认视图、日志面板高度和应用信息。当前设置中心按 `外观`、`偏好`、`帮助` 分组，默认打开 `外观` 页，并在页签上方固定显示应用信息。

## 入口位置

1. 打开应用主界面
2. 在顶部状态栏点击 `设置`
3. 设置中心默认会进入 `外观` 页
4. 按需切换到 `偏好` 或 `帮助` 页查看对应内容

## 当前可配置内容

### 1. 外观与主题

- 在 `外观与主题` 区域切换内置配色方案
- 当前内置主题包括：
  - Default
  - Sakura Pink
  - Ocean Blue
  - Aqua Glass（水玻璃）
  - Forest Green
  - Twilight Violet
  - Amber Orange
  - Mint Aqua
  - Rosewood Red

切换后会立即应用到当前界面。

### 2. 启动进入

可以设置应用下次启动时默认进入的工作台：

- `烧录工作台`
- `RTT 工作台`
- `串口工作台`
- `蓝牙工作台`
- `控制面板`
- `调试工作台`

适合长期只使用某一种工作模式的场景。

### 3. 背景显示

可以在默认打开的 `外观` 页首屏设置应用背景的显示方式：

- `保留当前背景`
- `自定义图片`

说明：

- `保留当前背景` 会继续使用当前主题自带的渐变和光斑效果
- `自定义图片` 支持从本地选择一张图片叠加到当前背景之上
- 透明度滑块只影响背景图片本身，不会影响面板和文字的可读性
- 选择完成后立即生效，并会在下次启动时保留

如果想回到初始状态，可以点击 `恢复默认` 清除已选图片并回到默认背景。

### 4. 主题方案

主题方案也位于 `外观` 页，但默认是更紧凑的折叠展示，避免打开设置时被主题卡片占满首屏。

切换后会立即应用到当前界面。

### 5. RTT 默认视图

可以设置 RTT 工作台默认展示方式：

- `仅文本`
- `分屏`
- `仅图表`

如果你经常一边看原始日志一边看波形，建议选择 `分屏`。

### 6. RTT 波形默认域

可以设置 RTT 进入波形工作流时默认打开的观察域：

- `Time 波形`
- `FFT 频谱`

说明：

- `Time 波形` 适合看原始采样变化趋势
- `FFT 频谱` 适合看主频、谐波和噪声分布

### 7. 串口默认视图

可以设置串口工作台默认展示方式：

- `仅文本`
- `分屏`
- `仅图表`

如果串口数据既要看原始文本又要做图表分析，建议选择 `分屏`。

### 8. 串口波形默认域

可以设置串口进入波形工作流时默认打开的观察域：

- `Time 波形`
- `FFT 频谱`

串口与 RTT 共用同一套波形 / FFT 工作流，因此使用习惯可以保持一致。

### 9. 日志面板高度

日志面板支持两种调整方式：

- 直接在工作台底部拖动日志面板分隔条
- 使用日志栏右上角按钮一键折叠 / 展开
- 在设置中心中通过滑块精确调整

应用会自动记住你最后一次设置的高度。

底部日志默认保持折叠，避免占用主工作区；展开后仍会使用已保存的高度。

在日志内容区右键，可将当前全部日志保存为 TXT；调试模式的“输出”面板也支持相同操作。

### 10. 应用信息与作者

页签上方的 `应用信息` 会始终显示当前版本和 `检查更新` 按钮。点击 `关于作者` 可查看作者主页和项目仓库；切换到任意页签时，这些入口都会保持可见。

### 11. 帮助与在线文档

`帮助` 页保留常用功能速查，并提供 `在线文档` 按钮。点击后会在系统浏览器中打开完整用户文档，查看快速入门、RTT、串口、图表、蓝牙和其他功能说明。

## 推荐使用方式

### 偏向 RTT 调试

建议这样设置：

- 背景显示：按个人喜好选择 `保留当前背景` 或自定义图片
- 启动进入：`RTT 工作台`
- RTT 默认视图：`分屏`
- RTT 波形默认域：`Time 波形` 或 `FFT 频谱`

这样打开应用后就能更快进入 RTT 采集和图表分析流程。

### 偏向串口采集

建议这样设置：

- 背景显示：如果需要更强的识别感，可以选择一张低透明度背景图
- 启动进入：`串口工作台`
- 串口默认视图：`分屏`
- 串口波形默认域：按你的数据类型选择 `Time 波形` 或 `FFT 频谱`

### 偏向日志观察

如果你主要看文本输出，建议：

- 背景显示优先使用 `保留当前背景`，避免图片干扰阅读
- RTT / 串口默认视图都设置为 `仅文本`
- 日志面板高度适当调高，方便同时查看系统日志

## 与波形 / FFT 的关系

设置中心只决定默认偏好，不会限制你在工作台中临时切换：

- RTT / 串口工具栏的 `更多` 菜单里可进入 `波形` 或 `FFT`
- `更多` 中的 `智能启用` 可以根据收到的数据自动识别图表配置

也就是说：

- 设置中心决定“默认打开成什么样”
- 工具栏决定“当前这次要怎么分析”

## 常见问题

### 改完设置后为什么没有重启应用？

大多数设置会立即生效；像“启动进入”这类偏好会在下次打开应用时体现。

### 调整日志面板高度后会丢失吗？

不会。高度会自动保存，下次打开应用时会恢复。

### 自定义背景图片会影响界面文字吗？

不会。透明度调节只作用于背景图片层，前景卡片和文字样式保持不变。

### 为什么切回默认背景后图片不见了？

这是预期行为。切回 `保留当前背景` 后，应用会恢复主题默认背景；如果你点击了 `恢复默认`，已选图片也会一并清除。

### RTT 和串口为什么都能设置 FFT？

因为两者都支持对数值流做波形和频谱分析。只要数据格式适合，RTT 和串口都可以走同一套图表分析流程。
