# 触发捕获

等某个条件成立时自动冻结图表，把那一刻**前后**的数据留住。串口、RTT 和蓝牙三个工作台都支持。

## 解决什么问题

图表默认是滚动窗口，只显示最近一段数据。想抓一次瞬时现象——电机堵转的瞬间、某个值越限、偶发的异常帧——就得一直盯着屏幕，而且等你看到时，缓冲区可能早就把它挤掉了。

触发捕获让软件替你盯着。条件一成立就冻结，你回来慢慢看。

**关键是它能留住触发之前的数据。** 因为图表本来就一直在缓存最近的样本，所以"事件发生前那 200 个点"是现成的——这正是排查问题最需要的部分。

## 怎么用

位置：工具栏 → 更多 → **触发捕获**（打开开关后展开设置）

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 通道 | 未选择 | 监视哪一路数据。列表中是当前可见的 Y 通道，隐藏的通道和 XY 散点图的 X 通道不在其中 |
| 条件 | 上升沿穿越 | 上升沿穿越 / 下降沿穿越 / 高于电平 / 低于电平 |
| 电平 | 0 | 触发阈值。波形示波器的时域视图中会画一条橙色虚线标出位置 |
| 样本 | 前 200 / 后 200 | 触发点之前保留多少个、之后再采多少个（触发点本身算作后置样本的第一个） |
| 模式 | 单次（触发后停住） | 单次（触发后停住）/ 正常（反复触发） |
| 呈现 | 只显示触发窗口 | 只显示触发窗口 / 显示全部并标注触发点 |

典型步骤：

1. 先让图表正常出数据（图表解析已启用、通道能看到实时值）
2. 打开 **触发捕获** 开关，选择通道、条件和电平
3. 面板底部显示 "等待触发"，此时可以离开去复现问题
4. 条件成立并采够后置样本后，图表冻结在本次捕获的画面上，面板显示 "已捕获，图表已冻结"，图表工具栏显示 "已冻结 · 触发捕获"，波形上有一条标着 "触发" 的橙色竖线标出触发那一刻
5. 看完点 **重新武装** 继续等下一次

触发判断在后台进行，图表视图收起时同样有效。

## 四种触发条件

**上升沿穿越 / 下降沿穿越** —— 数值从电平一侧跨到另一侧的那一刻才算。这意味着：

- 信号一直在电平之上不会触发，必须是"越过去"的动作
- 在电平附近抖动**不会**反复触发，因为每次穿越只成立一次
- 刚开始或刚重新武装时的第一个样本不会触发，至少要有前后两个样本才能判断穿越

**高于电平 / 低于电平** —— 只要当前值满足就算。适合"只要超过就抓住"的场景，比如监视温度是否越限。

> 分不清时优先用边沿。大多数"抓某个事件发生的瞬间"的需求，要的都是边沿。

## 两种模式

**单次（触发后停住）** —— 触发一次后停住，直到你手动点 **重新武装**。适合抓一个明确的、只会发生一次的现象。

**正常（反复触发）** —— 每次捕获完成后自动回到等待状态，继续判断下一次触发，不需要手动重新武装。图表冻结期间每完成一次新的捕获，画面就换成最新一次捕获，触发标记同步移动。适合观察反复出现的现象。

切换模式或关闭再打开触发捕获开关，都会让触发器从 "等待触发" 重新开始，之前的触发点不再保留。

## 两种呈现方式

**只显示触发窗口** —— 冻结画面只显示触发点前后那一段（前置 + 后置样本数），聚焦事件本身。这是示波器的做法，适合抓瞬态。窗口精确结束在最后一个后置样本上，即使同一批数据里在捕获完成后还有更多样本，也不会混进窗口。

**显示全部并标注触发点** —— 冻结画面保留捕获完成那一刻的整个缓冲区，只在触发位置画标记。适合想看事件在整体趋势里处于什么位置。

两种方式都不会裁剪后台缓存：点 "恢复跟随" 后图表回到完整的实时数据。呈现方式在捕获那一刻生效，已冻结的画面不随之后的切换改变，请在触发前选好。

## 前后置样本数怎么定

先想清楚要看的是**事件之前**还是**之后**：

- 排查"是什么导致了它"——加大前置样本数
- 观察"发生之后怎么变化"——加大后置样本数

两者之和不要超过图表配置 `性能与采样` 页中的 `最大数据点数`（默认 4000），否则前置部分会因为缓冲区不够而取不满。取不满不会报错，只是窗口比设定的短。

## 注意事项

**触发只在图表解析启用时工作。** 没有解析出数值就无从判断条件。没有任何可见通道时，面板会提示 "尚未配置任何可见通道，触发无法工作"。

**改了解析配置后要检查触发通道。** 通道列表变化后，原来选的触发通道可能已经不存在，面板会提示 "触发通道「xxx」已不在当前通道列表中，请重新选择"。

**清空图表会同时复位触发状态。** 图表工具栏的 "清空数据" 会让触发器回到等待状态——否则残留的"已触发"状态会让后续数据永远不再触发，而且很难看出原因。

**捕获后图表处于冻结状态**，与手动点 "冻结" 是同一个开关，但显示的是本次捕获的画面，而不是冻结前最后一帧。此时数据仍在后台接收，只是不刷新显示。弹出的独立图表窗口同样显示捕获画面和触发标记。

**单次模式下 "恢复跟随" 不等于重新武装。** 先点了图表的 "恢复跟随" 时，图表回到实时滚动，但触发器仍停在已捕获状态，面板显示 "已捕获，等待重新武装"，**重新武装** 按钮保留——点它即可开始等待下一次触发，不需要清空数据。

**关闭触发捕获开关**即可回到普通的滚动显示。

## 配合其他功能

- 冻结在捕获画面时，图表工具栏的 **导出** 保存的就是这次捕获的数据（CSV 或 PNG）
- 想反复分析同一段数据，用[会话录制](SESSION_RECORD_GUIDE.md)把原始数据存下来，之后回放
- 触发判断作用在**滤波后**的数值上，也就是你在图上看到的那条曲线。这样设电平时所见即所得；代价是[滤波配置](MATLAB_FILTER_GUIDE.md)会影响触发时机——滤波器的延迟会让触发相应推迟。想按原始信号触发就先关掉滤波
