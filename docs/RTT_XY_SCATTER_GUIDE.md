# RTT XY 散点图使用指南

## 功能概述

XY 散点图使用一列数据作为 X 轴、其余列作为 Y 轴的值，而不是用时间作为 X 轴。适合绘制李萨如图形、参数曲线、相关性分析等。

## 与普通散点图的区别

### 散点图（按时间）

- **X 轴**：相对时间（秒）
- **Y 轴**：数据值
- **适用场景**：时间序列数据、顺序数据

### XY 散点图

- **X 轴**：某个通道的实际数值（如角度、温度、电压等）
- **Y 轴**：其余可见通道的数值
- **适用场景**：相关性分析、参数曲线、李萨如图形等

## 数据格式

### 基本格式（两列）

每行一条记录，记得带换行符：

```
0,100
1,98
2,95
3,91
```

也可以使用制表符、空格或分号分隔：

```
10.5    25.3
11.2    26.1
12.0    24.8
```

### 带序号的三列格式

第 1 列是递增的整数序号，后两列是 X、Y：

```
20,4997.32,122954.44
21,4998.10,122960.02
```

智能启用会识别这种格式，并把序号列作为隐藏通道。

### 多系列格式（多列）

```
0,100,50
1,98,52
2,95,55
```

第一列作为 X 轴，其他列作为不同的 Y 轴系列。多系列格式需要手动配置，见下文。

## 使用方法

### 方法 1：智能启用（推荐）

适用于两列 XY 数据和 "序号, X, Y" 三列数据：

1. 启动 RTT 并接收 XY 格式的数据
2. 打开工具栏的 **更多**，点击 **智能启用**
3. 系统会自动：
   - 检测到 XY 数据格式和分隔符
   - 启用图表并配置为 XY 散点图
   - 创建通道 `x`（角色 X，读取第 1 个数值列）和 `y`（角色 Y，读取第 2 个数值列）
   - 当前是 "文本" 视图时切换到 "分屏"

### 方法 2：手动配置

1. 打开工具栏的 **更多**，在 "配置" 中点击 **图表配置**
2. 在 **基础** 页：
   - 打开右上角的总开关
   - 解析模式：选择 **分隔符**
   - 图表类型：选择 **XY 散点图**
   - 分隔符：填写实际使用的分隔符（如 `,`）；制表符写 `\t`
3. 切换到 **通道** 页，点击 **添加** 新建通道：

   | 键  | 列号 | 显示名称 | 角色 |
   | --- | ---- | -------- | ---- |
   | `x` | `0`  | X        | X    |
   | `y` | `1`  | Y 值     | Y    |

4. 点击 **保存配置**，切换到 "图表" 或 "分屏" 视图

> 通道页的 "角色" 列只在图表类型为 XY 散点图时显示。把某条通道设为 `X` 时，原来的 X 通道会自动改回 `Y`。

## 应用场景示例

### 1. 李萨如图形

**数据格式：**

```c
// 嵌入式代码
for (int i = 0; i < 360; i++) {
    float angle = i * 3.14 / 180.0;
    int x = (int)(sin(angle) * 100);
    int y = (int)(sin(2 * angle) * 100);
    SEGGER_RTT_printf(0, "%d,%d\n", x, y);
}
```

**效果：** 显示经典的李萨如图形（8 字形）

仓库的 `examples/gd32-rtt/` 示例工程输出的就是这组数据，烧录后点 "智能启用" 即可看到。

### 2. 参数曲线

**数据格式：**

```c
// 螺旋线
for (int t = 0; t < 360; t++) {
    float angle = t * 3.14 / 180.0;
    int x = (int)(t * cos(angle) / 10);
    int y = (int)(t * sin(angle) / 10);
    SEGGER_RTT_printf(0, "%d,%d\n", x, y);
}
```

**效果：** 显示螺旋线

### 3. 传感器相关性分析

**数据格式：**

```c
// 温度 vs 湿度（放大 10 倍输出，SEGGER_RTT_printf 不支持 %f）
SEGGER_RTT_printf(0, "%d,%d\n", (int)(temperature * 10), (int)(humidity * 10));
```

**效果：** 分析温度和湿度的相关性

### 4. 多系列 XY 图

**数据格式：**

```c
// X, Y1, Y2
for (int i = 0; i < 360; i++) {
    float angle = i * 3.14 / 180.0;
    int x = i;
    int y1 = (int)(sin(angle) * 100);
    int y2 = (int)(cos(angle) * 100);
    SEGGER_RTT_printf(0, "%d,%d,%d\n", x, y1, y2);
}
```

**配置（通道页）：**

| 键   | 列号 | 显示名称 | 角色 |
| ---- | ---- | -------- | ---- |
| `x`  | `0`  | 角度     | X    |
| `y1` | `1`  | 正弦     | Y    |
| `y2` | `2`  | 余弦     | Y    |

> 多系列数据不要用智能启用：像上例这样三列且第一列是递增整数时，会被识别为 "序号, X, Y" 格式（第一列当作隐藏的序号）；四列及以上会被识别为多列 CSV 并配置成波形示波器。请按上表手动配置，或智能启用后再到通道页调整角色和图表类型。

## 配置选项

### X 轴通道

在通道页把一条通道的 "角色" 设为 `X`，它的数值就作为 X 轴，X 轴标题显示该通道的显示名称。键名可以任意，例如 `x`、`time`、`angle`、`temp`。

### Y 轴通道

角色为 `Y` 且打开了 "显示" 的通道都会作为 Y 轴系列绘制。每个通道可以：

- 自定义显示名称和单位
- 选择颜色
- 显示 / 隐藏

图表工具栏的 **通道** 弹窗也可以修改名称和显隐。

### 显示范围

- 图表绘制缓存中的全部数据点（最多 "最大数据点数"，默认 4000）；超过 "可视点数"（默认 600）时会抽稀绘制
- X、Y 轴范围根据数据自动计算
- 底部的范围拖动条可以只看其中一段数据
- **冻结** 可以停住当前画面，**清空数据** 清除已绘制的点重新开始

## 智能检测逻辑

智能启用分析最近 20 行数据，判定为 XY 格式的条件：

1. 每行恰好包含 2 列数值（或 3 列且第 1 列为递增整数序号）
2. 每列都是普通十进制数值（支持负数和小数，不支持科学计数法）
3. 超过 80% 的行符合格式
4. 支持多种分隔符（逗号、制表符、空格、分号），自动选择匹配度最高的一种

检测成功后自动配置：

- 解析模式：分隔符
- 图表类型：XY 散点图
- 通道：`x`（角色 X）、`y`（角色 Y），三列格式另有隐藏的 `seq`
- 分隔符：自动选择的分隔符（制表符显示为 `\t`）

单列数值会优先识别为单数值波形，而不是 XY。

## 常见问题

### Q: XY 散点图和普通散点图有什么区别？

**A:**

- **散点图（按时间）**：X 轴是相对时间，适合时间序列
- **XY 散点图**：X 轴是某个通道的实际数值，适合相关性分析和参数曲线

### Q: 如何显示多条曲线？

**A:** 使用多列数据格式：

```
0,100,50,75
1,98,52,73
```

在通道页为每一列添加一条通道（列号依次为 0、1、2、3），把第一条的角色设为 `X`，其余保持 `Y`，它们会共享同一个 X 轴。

### Q: X 轴通道的键名必须是 "x" 吗？

**A:** 不是，可以是任意名称，只要：

1. 该通道的 "角色" 设为 `X`
2. 分隔符模式下 "列号" 指向正确的列
3. 全部通道中只有一个 `X`

### Q: 为什么图表不显示？

**A:** 检查以下几点：

1. 图表配置的总开关是否打开，图表类型是否为 "XY 散点图"
2. 是否有一条通道的角色为 `X`
3. 是否至少有一条角色为 `Y` 且打开了 "显示" 的通道
4. 各通道的列号是否和数据列对应
5. 数据格式是否正确（两列或多列数值，每行带换行符）

### Q: 可以实时更新吗？

**A:** 可以。XY 散点图支持实时数据流，新数据会自动添加到图表中，缓存满后最早的点被移除。

## 示例代码

### 完整的嵌入式示例

```c
#include "SEGGER_RTT.h"
#include <math.h>

void send_xy_data(void) {
    for (int i = 0; i < 360; i++) {
        float angle = i * 3.14159 / 180.0;

        // 李萨如图形
        int x = (int)(sin(angle) * 100);
        int y = (int)(sin(2 * angle) * 100);
        SEGGER_RTT_printf(0, "%d,%d\n", x, y);

        HAL_Delay(50);
    }
}
```

### 多系列示例

```c
void send_multi_series(void) {
    for (int i = 0; i < 360; i++) {
        float angle = i * 3.14159 / 180.0;

        int x = i;
        int sin_val = (int)(sin(angle) * 100);
        int cos_val = (int)(cos(angle) * 100);
        int tan_val = (int)(tan(angle) * 50);

        SEGGER_RTT_printf(0, "%d,%d,%d,%d\n", x, sin_val, cos_val, tan_val);

        HAL_Delay(50);
    }
}
```

对应的通道配置：`x`（列号 0，角色 X）、`sin`（列号 1）、`cos`（列号 2）、`tan`（列号 3）。

## 总结

XY 散点图特别适合：

- 参数曲线绘制
- 相关性分析
- 李萨如图形
- 轨迹追踪
- 多变量关系展示

两列 XY 数据配合智能启用即可一键出图；多列数据在通道页设置一次角色即可。更多图表操作见 [RTT 图表与波形](RTT_CHART_GUIDE.md)。
